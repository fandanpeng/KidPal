- **为什么改**：设备语音链路三个实测缺陷——① 每请求随机 session 无会话连续性，孩子 9-30 讲过的「王一诺」今天答不出（OpenClaw 原生记忆写端在收、读端三重封死）；② 单轮 DeepSeek prompt 实测 22,116 tokens（34 工具 schema 57KB），纪律被稀释且 cache miss 占大头；③ 课表回合幻觉可复现（v11 后仍漏读，TECH-261018 在案）。
