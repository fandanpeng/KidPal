## 1. 背景与目标

给 8–12 岁小朋友做一个随身学习伙伴。设备本地做「感知 + 显示 + 交互」，云端做「理解 + 生成 + 存储」。
三大核心功能：

1. **课表/日程助手** — 记录课表与培训班时间，支持查询与提醒。
2. **故事记录** — 听孩子口述故事，实时转写并归档保存，可回听/回看。
3. **查生字** — 孩子问「某个字怎么写」，设备把汉字的**笔顺/写法**清晰显示出来。

## 2. 硬件能力盘点（依据本地官方 Demo 实测确认）

| 模块 | 型号/配置 | 说明 |
|---|---|---|
| 主控 | ESP32-S3-WROOM-1-N16R8（双核 240MHz） | Wi-Fi + BLE5，512KB SRAM + 384KB ROM，**16MB Flash + 8MB PSRAM** |
| 屏幕 | **RLCD 反射式，ST7305 驱动，400×300 横屏(300×400竖)，1bpp 单色** | 4.2寸。SPI(SCK11/MOSI12/DC5/CS40/RST41)。无背光靠环境光，越亮越清晰，暗处不可见(本板文档未列前光→大概率无)，超低功耗可常显。一帧 400×300÷8=15KB。**刷新快(~45-70 FPS)，可动画/滚动/实时刷新**。ST7305 支持局部窗口更新+低功耗模式 |
| **按键 ×3** | **KEY（自定义）、BOOT（GPIO0）、PWR（电源）** | KEY=自定义功能键；BOOT=按住上电进下载模式/平时可自定义；**PWR=长按关机/单击开机，为硬件电源电路键，固件不可读（官方全部 Demo 无 PWR 读取代码，文档描述"长按下电/单击上电"为电源管理行为）→ 实际可用功能键=KEY+BOOT 两个**。multi_button 支持单击/双击/长按。如需第三键可经 2×8 排母 GPIO 外扩 |
| 触摸屏 | **无** | 交互全靠按键 + 语音 |
| 音频输入 | ES7210 ADC + **双麦克风阵列** | 支持降噪/回声消除，可做近场/远场语音识别与唤醒（当前用"按一下启动会话"） |
| 音频输出 | ES8311 codec + PA（MX1.25 2PIN 扬声器接口） | I2S 放音，可播放提示音/语音 |
| RTC | PCF85063（I2C）+ **RTC 独立备用电池座** | 走时提醒，主电/RTC 独立续航，掉电保持 |
| 传感器 | SHTC3 温湿度 | 辅助（可显示环境温度湿度） |
| 存储 | Micro SD 卡槽（FAT32）+ 16MB Flash | 板端非易失介质仅存设备凭证、1bpp 美术资产/字体、固件本体；业务数据不落板（决策 24） |
| 电池 | **18650 锂电池座 + 充放电管理** | 便携；ADC 测电压电量；CHG充电/WRN反接指示灯 |
| 扩展 | 2×8 排母(2.54mm) + USB/UART/I2C/GPIO | 可扩展前光等 |

> 关键约束（已据官方文档修正）：
> - **400×300 单色 1bpp**：UI 用黑/白两色 + 抖动(dithering)模拟灰度。
> - **刷新快（~45-70 FPS）**：与普通 LCD 相当，**可做流畅滚动、动画、笔顺动态演示**——非墨水屏那种慢。这解放了 UI 设计。
> - **反射式无背光**：暗处不可见（本板大概率无前光，待确认），阳光下极佳、超低功耗、可常显「今日日程」。
> - **图形库**：沿用**小智自带 LVGL**（单色模式），笔顺用 `lv_canvas` 绘制，不重写显示层。（u8g2 官方虽主推单色，但换它需重写显示层，基于小智改则沿用 LVGL 更省事。）
> - ST7305 支持局部窗口更新，可按需优化功耗。
> - 语音是主要输入方式（孩子打字不便），配合少量物理按键。
>
> 环境硬要求：arduino-esp32 **v3.3.0+**，U8g2 **v2.36.19+**（才含 ST7305 300×400 支持）。

## 3. 系统架构

### 3.0 顶层定位（已定 ✅：OpenClaw 编排层 + 板子终端）

> 这是与用户对齐后的核心定位，统领整个架构。

```
【ESP32 板子】= 终端（"会说话的显示器"）
   只负责：麦克风收音、扬声器放音、屏幕显示、按键交互
   ❌ 不理解业务、❌ 不存数据、❌ 不做智能

【OpenClaw】= 编排层 + 主 Agent（大脑 + 记忆 + 工具）
   负责：听懂(ASR)、理解意图(DeepSeek)、执行功能、记忆存储(MD 文件)、回复(TTS)
   ✅ 所有数据、逻辑、记忆都在这里
```

**核心原则**：板子是个"哑终端"，一切智能与记忆在 OpenClaw。板子通过一套**约定的数据格式**接收"屏幕要显示什么"，只负责渲染。课表存成 MD、故事存成 MD、生字笔顺由 OpenClaw 按格式输出——板子拿来就画。

### 3.0.0 服务端架构（已定 ✅ 2026-09-02 更新：流式网关 + OpenClaw 大脑）

> 关键发现（沿用）：OpenClaw 网关自带 **OpenAI 兼容 API（`POST /v1/chat/completions`，2026-09-02 实测支持 `stream:true` token 级流式）**，跑的是完整 agent（意图理解/多轮会话/读课表MD/存故事/查字/记忆/工具调用全包）。**业务网关、CRUD、意图层全部不需要自研**。
> 方向更新（2026-09-02 human 裁定，待对抗 review 冻结）：端云通信由「MVP 同步 HTTP」转为 **WebSocket + Opus 流式（方向 B）**，服务端借鉴官方开源小智服务端实现，不逐行自研流式编排。

```
【ESP32 设备】(家里，小智 V2.1.0 基座原生 WS+Opus 管线)
   │ 设备 token（弱权限，WS 握手 Bearer）
   ▼ 公网 wss（自签证书；小智协议：hello 协商 + Opus 二进制帧 + JSON 消息）
【流式网关】xinnan-tech/xiaozhi-esp32-server（开源 MIT，部署于 ECS，唯一公网入口）
   上行：Opus 16kHz/60ms 帧 → VAD 切句 → ASR（阿里云云 ASR，云优先）
   下行：LLM token 流 → 句级切分 → TTS（edge-tts）→ Opus 24kHz 帧
   推送：display JSON 走 mcp kidpal/display 工具；提醒走 mcp kidpal/alert 工具（服务端定时推送）
   │ loopback + 真 token（真 token 不出内网）
   ▼
【OpenClaw 网关】大脑 —— OpenAI 兼容端点（type=openai 配置级接入；流式请求禁带 max_tokens，实测坑）
```

**砍掉**（沿用）：自研业务网关、CRUD 接口、会话/意图层（DeepSeek+多轮对话自带）。
**保留（极薄，形态变化）**：音频转换（ASR/TTS 走网关 provider 插件）+ 设备鉴权 + 提醒推送；「零自研业务逻辑」的薄桥红线不变，变的是承载形态（HTTP 四端点 → 小智协议剖面 + provider 配置 + 小段 push helper）。

**迁移与既有资产**：
- Pod S（260829-smoke-e2e）的同步 HTTP 链路（四端点 + WAV 上行/MP3 下行）为**架构验证台阶**（live 5/5 实证），方向 B 落地后退役；其安全发现（401 门穿透与修复、设备 token 纪律）沿用。
- 服务端实现形态：官方开源服务端 **Python 版**（xinnan-tech/xiaozhi-esp32-server，2026-09-02 grilling 选定；Go 社区版弃选——社区小、provider 覆盖未验证；配置级接 OpenClaw/edge-tts，ASR 走阿里云云端）+ 两个小补丁（结构化下发 push helper、提醒定时推送，各约几十行）。
- **语音喊停靠本地**（AEC+VAD 本地停播）不变；WS 通道下云端取消生成（abort 消息）成为补充能力。

### 3.0.2 待与 OpenClaw 对齐的关键格式

#### ✅ D3 笔顺数据格式（已定稿，OpenClaw 已实测跑通）
数据源：**makemeahanzi**（HanziWriter 同款开源数据，9574 字 / 32MB，已下载到服务器 `kidpal/chardata/`）：
- `dictionary.txt`：拼音、部首、结构（如 ⿱甬力）、笔画数、释义
- `graphics.txt`：每笔一个 SVG path + medians 骨架点

**单字 JSON（实测"勇"字约 2KB）**：
```json
{
  "type": "char",
  "char": "勇",
  "pinyin": "yǒng",
  "radical": "力",
  "strokeCount": 9,
  "strokes": ["M 547 677 Q ...", "..."],
  "medians": [[[x, y], ...], ...],
  "structure": "⿱甬力",
  "meaning": "勇敢；有胆量"
}
```
- `strokes`：9 条 SVG path（1024×1024 坐标系），用于逐笔填充显示字形。
- `medians`：每笔骨架中线点序列，"笔尖"沿它移动做写字动画（HanziWriter 同机制）。

**板子端渲染要点**（确定性，无技术风险）：
- **坐标变换**：1024×1024 → 400×300。注意 makemeahanzi Y 轴朝下且字形偏上，需翻转+偏移。
- **SVG path 解析**：路径含 M/Q/L/Z（二次贝塞尔）。板子端用轻量解析器把贝塞尔离散成点，LVGL `lv_canvas` 逐点绘制，或简化为折线逼近（1bpp 下视觉差异小）。
- **1bpp 光栅化**：矢量轮廓 scanline 填充成黑白位图，逐笔叠加显示。

- RLCD 显示驱动（custom_lcd_display）、Wi-Fi、Opus 编解码、MCP 工具框架、LVGL

**我们基于它改：换后端（接 Aliyun+OpenClaw）+ 重做 UI（4页结构）+ 加课表/故事/查字业务。** 不用从零整合音频/AEC/显示底层。

### 3.2 端云职责划分（已修正：本地做实时音频处理）
> 关键修正：全放云端会有"gap"——喊停/打断要求即时响应，等云端来不及。**实时的音频信号处理必须放本地 ESP-SR；理解语义才放云端。**（这正是小智架构）

| 能力 | 位置 | 说明 |
|---|---|---|
| **AEC 回声消除** | **本地**（ESP-SR AFE） | 边放音边录音消回声，实时性 |
| **VAD 语音活动检测** | **本地**（ESP-SR AFE） | 检测孩子插话/喊停，即时 |
| **唤醒词检测** | **本地**（ESP-SR WakeNet） | 二期唤醒用 |
| **喊停/打断检测** | **本地**（AEC+VAD 检测到人声即停播） | 必须即时，不等云端 |
| **会话管理**（按一下启动/超时关/结束关） | 本地状态机 | 基于小智 ToggleChatState 改 |
| **ASR（自由语音→文字）** | **云端**（阿里云云 ASR，音频流式上行、服务端 VAD 切句） | 开放语句本地识别不了 |
| **意图理解/对话/纠正** | **云端**（OpenClaw+DeepSeek，`/v1/chat/completions`） | 重智能，含"别讲了/不对"等控制指令理解 |
| **TTS 语音合成** | **云端**（edge-tts，网关 provider；语音随提醒推送下发，见 S-F1.4） | 晓晓/云希童声 |
| **课表/故事/查字业务+存储** | **云端**（OpenClaw，MD 文件） | |

### 3.4 核心请求链路（以查字为例）
```
孩子按一下 KEY（或二期喊唤醒词）→ 设备进入对话态，本地 AFE 开始聆听（本地 VAD 专职喊停/插话）
  → 孩子说"勇敢的勇怎么写" → Opus 帧持续流式上行 → 服务端 VAD 切句 → 云 ASR 转文字
  → 网关转发 OpenClaw（OpenAI 兼容端点，流式）
  → OpenClaw/DeepSeek 判意图=查字，提取"勇"，查 makemeahanzi 组笔顺 JSON
  → LLM token 流→句级切分→edge-tts→下行 Opus 帧播放；display JSON 经 mcp kidpal/display 下发板子
  → 板子：屏幕画"勇"+笔顺演示，扬声器播读音
  → 若 AI 讲太长，孩子喊"别讲了"→ 本地 AEC+VAD 检测人声→立即停播→发 `abort` 消息云端取消生成
```
**设备固件保持"笨"而轻，所有 AI 能力都在服务端**，便于随时升级模型而不动终端。

- **送达与出队（第二轮 grilling 定 + V14 解耦口径）**：**重试到确认**——网关推送后等渲染回执，超时 60 秒未收到即重推，单档上限 3 次，不做重连即重推，过期仍未送达 = 静默作废不补发。两个机制解耦（四态 received/queued/rendered/acked）：① **幂等去重 = 接收即入集**——设备接收到条目（入队前）即把 id 记入易失 known-id 集合，仅用于屏蔽重复入队，与渲染无关；② **回执出队 = 渲染即发**——回执仅在弹窗渲染完成时发出（渲染即确认、即出队，守住已裁取舍）。同 id 重推两态分处：已渲染 → 补回回执（重复弹窗根除）；排队未渲染 → 去重不重复入队、不回执，等渲染后回。

- **主动播报（2026-09-02 human 定）**：提醒到达 = 提示音 + **TTS 读出文案**（如「明天美术课，别忘了带画具！」）+ 弹窗驻留三件套同时发生——孩子不看屏也能听到；alert 载荷带 `speech` 字段，网关合成 TTS 随推送一并下发音频。
- **speech 合成解耦（V20 定）**：`speech` 于**排程时预合成**存缓存、到点随推送下发（消除到点实时合成的同步依赖）；合成失败/超时 → 降级「仅弹窗+提示音」继续投递、不阻塞；edge-tts 被封同理退化。**弹窗+提示音必达**，语音为可选增强。
- **过期数据清理（V34 定）**：提醒档位的过期作废见上；schedule.md 内过期一次性安排 = 查询时 OpenClaw 按当前时间过滤（已选），**MVP 不做归档**（增长治理留后续，若日后启用归档则 owner = OpenClaw 侧 cron）。
- **带物回读（V17 定）**：带物/备注除 20:30 档提醒外，可经语音问课表读回（S-F1.3 验收明确备注列参与答复）——错过提醒不等于信息蒸发。

## 5. 交互与 UI 设计（400×300 黑白 1bpp RLCD 约束）

### 5.1 设备定位与应用过程
它**首先是个"常显的信息牌"，其次才是语音交互设备**。平时 90% 时间常显在桌上/书包旁，孩子瞟一眼就知道现在几点、待会干嘛、屋里多少度；孩子有事了才按键交互。

```
【常显状态】屏幕常显（反射屏不耗电）：时间 + 今日日程 + 温湿度 + 电量
【交互状态】按一下 KEY 启动会话（免提说话）/ 按 BOOT 翻页 → 设备响应 → 超时或按键自动回首页
```

### 5.2 语音交互模型（已定：按一下启动会话 + 语音喊停）
**核心：按键只是"激活开关"，一旦激活进入免提会话，无需一直按住。**

```
【常显】屏幕常显信息牌（时间/日程/温湿度）
   │ 按一下 KEY（≈喊了唤醒词）
   ▼
【对话态】设备提示音+屏幕显示聆听中，本地 AFE(AEC+VAD) 启动
   │ 孩子说话 → Opus 帧持续上行、服务端 VAD 切句送云理解（本地 VAD 专职喊停/插话）→ 设备回应 → 继续聆听
   │ 可连续追问，不用每次按键
   ▼
【结束】三种任一：
  ① 超时：60 秒无语音 → 自动关闭，回常显
  ② 孩子说"拜拜/不用了" → 云端判为结束意图 → 关闭
  ③ 再按一下 KEY / BOOT → 手动关闭
```

**语音喊停（MVP 必做）✅**：AI 播放中，本地 AFE 持续跑（AEC 消回声 + VAD 检测人声）。
- **行为定义**：AI 播放中孩子**一开口（不管说什么）AI 立即停下并聆听**——既是喊停又是自然插话。
- 本地 AEC+VAD 检测到人声盖过播放声 → **立即停播（不等云端）** → 把孩子这段送云端 ASR → 云端判断："别讲了"→确认停止；"不对，是勇敢的勇"→纠正重答。
- 依赖 AEC 效果，音量过大/混响强时可能误触发或漏触发，**需实测调阈值**（最大不确定点）。
- 兜底：KEY 单击 = 随时打断停播（100% 可靠）。

**为什么本地做**：全放云端有"gap"——喊停/打断要即时响应，等云端来不及。实时音频处理（AEC/VAD/喊停）放本地 ESP-SR，语义理解放云端。

**二期唤醒词**：硬件已支持（双麦+ES7210），小智已集成 WakeNet。届时按一下 KEY 可替换为喊唤醒词，其余会话逻辑不变。

### 5.3 按键定义（3 键，无触摸）
| 键 | 单击 | 长按 | 备注 |
|---|---|---|---|
| **KEY**（主功能键） | **启动/结束会话**；对话中=打断停播；列表中=确认/下一项 | 回首页 | 核心交互键 |
| **BOOT**（辅键） | **切换页面（循环）**；对话中=也可结束会话 | 配网/特殊 | 小智默认 BOOT=ToggleChatState，可复用 |
| **PWR**（电源键） | 单击开机 | 长按关机 | 电源管理 |

核心逻辑：平时 BOOT 翻页浏览；有事按一下 KEY 进入语音会话（免提连续对话）；说完自动/手动结束回首页。对话中再按 KEY 可打断。

> 注：小智默认用 BOOT 做 ToggleChatState。我们改为 KEY 主司对话、BOOT 主司翻页。**权威键位手势（含双击、页内特例）以 §4.0 全局按键手势表为准**，本节为上表概览；最终手感在 UI 联调时微调。

### 5.4 页面结构（4 页循环）
```
        BOOT 单击 → 切下一页（循环）
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ P1 首页  │→ │ P2 课表  │→ │ P3 故事  │→ │ P4 查字  │→┐
│时间日程  │   │本周课程  │   │我的故事  │   │笔顺演示  │ │
│温湿度    │← │         │← │列表     │← │         │←┘
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

- **P1 首页**（常显默认）：时间+日期+温湿度+今日接下来日程+电量。按一下 KEY 启动语音会话；到点自动弹提醒（亮屏+提示音）。
- **P2 课表页**：今天/明天课程列表。BOOT长按切"今天/明天"；语音问"明天有什么课"→播报+滚动定位到对应行。课表页只承担"看安排"，不做"当前课"指示（见 §4 S-F1.2）。
- **P3 故事页**：我录的故事标题列表。KEY单击光标下移选择，KEY双击进入阅读/播放选中；语音说"我要讲故事"→进入录音（显示●录音中），说完自动/按键停止并上传。
- **P4 查字页**：超大字形+拼音+笔画+笔顺演示。语音说"勇怎么写"→整屏显示；KEY单击播/重播笔顺动画（逐笔写出）；继续说"勇是什么意思"→释义组词；想查下一个字直接语音说。

### 5.6 UI 风格
- 大字体、高对比黑白、图标化。RLCD 刷新快（~45-70 FPS），**滚动、简单动画、笔顺动态演示都可行**，不必局限于翻页式。可用抖动(dithering)模拟灰度层次。
- **趣味性要求（v2，孩子反馈"太正式"后确立）**：设计需有**吉祥物角色「小伴」（猫咪）**贯穿全局（首页常驻 + 各状态换姿态：聆听/思考/播报/录音/提醒），手绘感圆胖线条、拟人化细节（眨眼冒号、卡通温度计、故事果收集）、克制的涂鸦点缀。检验标准：孩子第一反应是"它好可爱"，不是"这是个闹钟"。详见 [UIUX-DESIGN-BRIEF.md](ui/UIUX-DESIGN-BRIEF.md) §3.1。
- **查字页教学字体红线（v3）**：P4 是教学页，**米字格大框里演示笔顺的示范汉字必须用标准规范字体**（思源黑体/楷体），禁用手写趣味体/抖动/倾斜——孩子会照写，不能教歪。拼音、部首、组词等伴随文字可保留可爱趣味字体。详见 brief §3.3。
- **查字界面**：整屏米字格大框内显示一个超大汉字（充满米字格字盘，设计稿框 236px/字盘约 208px）+ **笔顺逐笔动态演示**（像写字一样一笔笔画出来，教学效果好；可配"握笔小手"沿骨架移动）。
- **暗光问题**：反射屏暗处不可见 → 本板大概率无前光，定位光线充足环境使用（待确认）。

## 6. 端云接口

### 6.1 端云通信面（2026-09-02 更新：WebSocket + Opus 流式，小智协议剖面）
| 通道/消息 | 方向 | 内容 |
|---|---|---|
| WS hello 握手 | 双向 | 设备自报 `opus 16kHz/60ms 单声道`；服务端回 `session_id` + 下行 `audio_params`（采样率/帧长，默认 24kHz）；握手头带设备弱 token（Bearer）；传输层 wss + 自签长期证书（CA 嵌入固件） |
| 上行 Opus 二进制帧 | 端→云 | BinaryProtocol v2/v3 帧；服务端 VAD 切句后送云 ASR |
| `stt`/`tts` 状态消息 | 云→端 | 识别文字上屏 / 播报状态机（start、sentence_start 带文字、stop） |
| 下行 Opus 帧 | 云→端 | TTS 音频流（句级流水线：LLM token 流→句切分→TTS→Opus） |
| `mcp` 消息（JSON-RPC tools/call） | 云→端 | 两种载荷合一：**display 显示指令 JSON**（kidpal/display 工具，E1，view=char/schedule/story_list/story_text/text/home/control）与**提醒推送**（kidpal/alert 工具，三段阶梯，见 S-F1.4）；**设备 JSON-RPC 回执 = 送达确认**（提醒出队的 ack 通道）；小智原生 alert/custom 通道弃用（2026-09-02 grilling 裁定） |
| `abort` 消息 | 端→云 | 喊停/打断 → 云端取消生成（本地 AEC+VAD 即时停播之外的补充） |
| `llm`/`system` 消息 | 云→端 | 小智原生：`llm`（emotion 表情，本项目 UI 重做不消费、弃用）/ `system`（reboot，二期 OTA 保留）（V12 补齐枚举） |
| `listen`/`ping` 等 | 双向 | 会话控制与保活（小智协议既有） |

> 业务接口（课表 CRUD、故事、查字）**全部不需要**——由 OpenClaw 完整 agent 经 OpenAI 兼容端点统一处理（网关以 `type:openai` 配置级接入；**流式请求禁带 `max_tokens`**，2026-09-02 实测会触发 agent incomplete-turn 报错），结果通过 display 指令经 `custom`/`mcp` 消息下发。详细契约见 [docs/contracts/interface-contract.md](../../contracts/interface-contract.md)（**注**：契约现有 HTTP 四端点/轮询形状待契约门按本方向重写为小智协议剖面节，CDQ-260902 在办）。
> 迁移期注记：Pod S 的 HTTP 四端点形态（/v1/asr /v1/chat /v1/tts /v1/alerts，WAV 上行/MP3 下行）为已验证的架构台阶，方向 B 落地后退役。

## 7. 关键技术决策

### 已定 ✅
1. **顶层定位**：**OpenClaw 作编排层+主 Agent（大脑/记忆/工具），板子只作"会说话的显示器"终端**。所有数据/逻辑/记忆在 OpenClaw（课表存MD、故事存MD、笔顺由OpenClaw按格式输出）；板子只收音/放音/显示/按键。
2. **技术路线**：**基于小智(XiaoZhi V2.1.0) 二次开发**（官方已移植本板，含 AFE唤醒+AEC+VAD、全双工音频、显示、Wi-Fi、Opus、LVGL）。换后端接 Aliyun+OpenClaw + 重做 UI + 加业务。
3. **端云划分**：本地做**实时音频处理**（AEC/VAD/唤醒/喊停检测/会话管理），云端做**语义理解**（ASR/意图/对话/TTS/业务）。
4. **服务端架构**：**薄桥 shim（FastAPI ~200行，唯一公网入口）+ OpenClaw 自带 OpenAI 兼容 API**。OpenClaw 网关有 `POST /v1/chat/completions`（默认关闭，开启即可），跑完整 agent（意图/会话/读课表MD/存故事/查字/记忆/工具全包）。**业务网关/CRUD/意图层零自研**。shim 只做 ASR/TTS HTTP 口子 + 设备鉴权 + 提醒轮询。⚠️ **已被决策 9/18 取代**：方向 B 转官方小智服务端网关，HTTP shim 退役为已验证台阶（spec §3.0.0「迁移与既有资产」）。
5. **OpenClaw 部署**：阿里云成都 ECS（公网 ws://8.137.91.16:18789 已验证通，内网 172.26.11.60）。shim 与 OpenClaw 同机，loopback 调用，真 token 不出内网。
6. **ASR/TTS**：放 OpenClaw 机器（faster-whisper + edge-tts，待装），经 shim `/v1/asr`、`/v1/tts` 暴露。⚠️ **已被决策 19 取代**：ASR 云优先（faster-whisper 弃选）；edge-tts 保留为网关 provider。
7. **语音交互**：**按一下 KEY 启动会话**（≈唤醒词体验），免提连续对话，60秒超时/说"拜拜"/再按键 结束。二期加 WakeNet 唤醒词。
8. **语音喊停（MVP 必做）**：**本地** AEC+VAD 停播（不依赖云端取消生成）。KEY 单击打断兜底。方向 B 的 WS 通道下，`abort` 消息使云端取消生成成为补充能力（省算力，不改变本地即时停播的主地位）。
9. **端云通信（2026-09-02 更新）**：**WebSocket + Opus 流式（方向 B）**——human 裁定，待对抗 review 冻结。服务端借鉴官方开源小智服务端实现（xinnan-tech/xiaozhi-esp32-server，MIT，活跃），不逐行自研流式编排。Pod S 的同步 HTTP 链路为架构验证台阶（260829-smoke-e2e live 5/5），迁移后退役。
10. **使用形态**：**便携电池为主**（18650），故二期唤醒需实测功耗。
11. **语言大脑**：OpenClaw + DeepSeek，意图理解、对话、任务分发、纠正/结束判定。
12. **汉字笔顺**：✅ D3 格式定稿——makemeahanzi 数据源（已实测跑通），OpenClaw 组 JSON（strokes SVG path + medians 骨架点），板子只渲染（LVGL 绘制 + 逐笔动画）。
13. **课表/故事存储**：OpenClaw 存 MD 文件；课表录入主路径为家长端。
14. **页面结构**：**4 页循环**（首页/课表/故事/查字），BOOT 单击循环切换。

18. **服务端实现形态（2026-09-02 新增 + grilling 定）**：**官方 Python 版**小智服务端（xinnan-tech/xiaozhi-esp32-server；Go 社区版弃选——社区小、provider 覆盖未验证）+ 适配插件——LLM 经 OpenAI 兼容端点配置级接入 OpenClaw（`type:openai`，base_url/api_key/model 可配；**流式请求禁带 `max_tokens`**）；TTS=edge-tts（可替换 provider）；ASR=阿里云云端（云优先，见决策 19）；自写部分仅结构化下发 push helper 与提醒定时推送（各约几十行）。
19. **ASR 云优先（2026-09-02 新增，待冻结）**：前期用阿里云云 ASR（Qwen3-ASR-Flash / Aliyun 流式，与 ECS 同区、按量计费+免费额度），避免前期订阅服务器扩容；兜底触发 = 额度用尽 / 隐私需求变化 / **云 ASR 流式不达标（与 VAD 切句语义不兼容）**（V23 补）→ 升级 ECS 切本地 SenseVoice（官方服务端 `fun_local`，配置级切换、无返工）。「ASR = 可替换 provider」写为架构前提。**儿童数据出网记账（human 2026-09-03 确认，V29 定）**：① 语音音频 → 阿里云 ASR（境内）；② 转写文本 → OpenClaw → DeepSeek 云（deepseek-v4-flash）；③ 回复文本 → edge-tts（微软非官方接口）——三条路径均出内网，human 已知晓并接受；原「仅 ASR 链路」措辞废止。
20. **提醒模型（2026-09-02 新增 + 三轮 grilling 定）**：**按区块判范围**——「学校课程表」区块不提醒（在校例行）；「每周固定课表」区块（培训班，不论周中周末，**每周重复生成**）+ 一次性安排走三段阶梯（前一天晚上 20:30 带物 / 当天早上 07:45 日程 / 事前 15 分钟——**时刻为 2026-09-02 human 修订值**，全局常量**配在 OpenClaw 侧**、不进契约）；携带内容复用课表备注列、解析规则由 system prompt 约定（契约 B1 表格主体零变更；frontmatter `remind_before_min` 字段废止、待契约门裁）；定时器 = **OpenClaw 原生 cron**（2026-09-02 ECS 实测：调度器在跑、已有 class-reminder 类任务运行记录、`cron --message` 可定时触发 agent 回合）；**脑算网关推**（OpenClaw 算三档写 pending.json、网关只到点推送）；载体走 mcp（见决策 23）；**重试到确认**（60 秒超时重推、单档上限 3 次、不做重连即重推、过期静默作废），**渲染即确认出队**（KEY/BOOT 只关弹窗；弹窗无超时驻留、多提醒排队逐个弹；设备易失 id 集合幂等去重）。
21. **连接策略（2026-09-02 grilling 定）**：常驻连接（设备开机即连、断线重连），保提醒推送/打断可达；省电不预设优化，功耗实测后再看（决策 10 便携电池优先）。**实测 DEFER 三要素（V24 定）**：触发点 = 阶段 C 硬件验收包跑实机续航基准；预警 = 续航 < 阈值 → 降级（加大心跳间隔 / AFE 常显休眠 / 降刷新）；owner = 硬件验收包，相位写入重切后里程碑。
22. **传输安全与鉴权（2026-09-02 grilling 定 + 2026-09-03 拍板回灌）**：wss + 自签长期证书——**有效期 ≥10 年**（把到期死局推出产品生命周期，V25 定）+ 轮换机械脚本 + 到期前告警（owner = 方向 B 落地包；部署期相位对账：证书有效期 vs OTA 建立，若 OTA 必晚于首期续证则 OTA 提前或显式记账死局，ARQ-260902-cert-lifecycle-deadlock）；CA 嵌入固件的证书加载实现面见 dev-loop handoff V10。**设备 token = 全设备共享单 token**（human 2026-09-03 裁，V26 定；MVP 单设备场景；已知取舍 = 无每设备身份、单点泄露危及全部、多设备时转每设备唯一并记账）；强度 ≥128-bit 随机、服务端 constant-time 比对、配网时生成写入。**强制设备鉴权**——token 未设 = 拒绝服务，公网入口不留 validation-mode 后门。**18789 收敛 = 方向 B 落地前硬前置**（V28 定）：OpenClaw 18789 锁 127.0.0.1（安全组/防火墙，部署期断言），与 ARQ-260901 复议触发合并。

25. **故事录入流式机制（2026-09-02 第三轮 grilling 定）**：manual 聆听模式 + 网关累积（开始信号 = E1 control 扩展 `start_recording`，停录整段转写归档）；闲聊（VAD 自动断句逐句进对话）与录故事（累积到停）两条聆听语义正式分流。
