## 1. 产品一句话

一款面向 **8–12 岁孩子**的桌上学习伙伴：平时是**常显的信息牌**——孩子瞟一眼要回答的是「**接下来我该干嘛**」（日程 + 小伴演出为主体，时间/温湿度退居辅助位），其次才是语音交互设备；孩子按一下键或喊一声，就能问问题、记故事、查生字。

- **对话是主路径**：通用问答兜底一切随口之问；三项专项能力（问课表 / 帮我记录 / 查生字）都由对话发起。
- 常显页别做成「现在几点、屋里多少度」的信息牌构图——环境信息不与日程抢视觉重心。

## 2. 硬约束（设计必须遵守，不可违背）

### 2.1 屏幕（最关键）
| 项 | 值 | 设计含义 |
|---|---|---|
| 尺寸/比例 | **400 × 300 像素，横屏（4:3）** | 所有设计严格在这个画布内 |
| 色彩 | **纯黑白 1bpp（每像素非黑即白，无灰阶）** | 只能用纯黑/纯白两色；灰色层次只能用抖动(dithering)/网点/线条纹理模拟——**网点全局口径待拍**（见 §7） |
| 类型 | 反射式 RLCD，无背光 | 靠环境光，**高对比、大留白、粗线条**更清晰；暗处看不清，不依赖颜色深浅表达信息 |
| 刷新 | 快（~45-70 FPS） | 滚动、简单动画（笔顺逐笔写出、盖章定格、声波）都可行，但 UI 以静态清晰为主 |

### 2.2 输入方式（影响交互设计）
- **无触摸屏**。
- **只有 3 个物理按键**：
  - **KEY**（主键）：**短按 = 当前语境的主操作**（唤起会话 / 播报中打断 / 查字窗重播等）；**长按 = 返回上一层**（查字窗/提醒弹窗 = 关窗回原页 · 语音会话中 = 结束会话回原页 · P3 阅读 = 退出回列表 · 录音态 = 取消录音丢弃已录 · 三主页面 = 回首页）。
  - **BOOT**（辅键）：**主屏 = P1→P2→P3 三页循环翻页**；**列表 = 光标下移（双击 = 翻下一屏快速跳屏）**；**阅读态 = 翻屏**；**覆盖层（提醒弹窗/查字窗/语音轮演出/正文取不回提示）内 = 关掉顶层回原页、不翻页**。
  - **PWR**：开关机，不入界面流程。
- **语音双入口**：按 KEY，或喊唤醒词（Phase 1 用「你好，小智」；品牌定制词「你好，小伴」属后续）。
- **主要靠语音交互**（孩子说话）。

> 设计含义：界面上不需要"可点的按钮"，操作提示 = "按 KEY / 按 BOOT"这类物理按键引导，统一住在底部键帽条（见 §2.3）。导航动作有四类：**翻页 / 页内前进（光标、翻屏）/ 主操作 / 返回上一层**——不是只有"翻页和确认"两种。键位逐语境的完整权威 = requirements §2.3。

### 2.3 底部键帽条（全局 chrome）
`comp-keybar` = 通栏贴底**三槽**：**左 KEY 提示 · 正中 3 点页面指示器（当前页实心放大）· 右 BOOT 提示**。高 38px、上沿 3px 实线分隔；键帽高 26px / 圆角 8px / 3px 描边 / 圆胖数字体。**它是提示不是按钮**（无触摸、不画可点样式）；需要长按的键帽左侧挂小字「长按」。**条在任何状态常驻**（基座 chrome，覆盖层盖不掉）；**页点仅 P1–P3 主页面显示，覆盖层不显示页点**。左右槽文案随页面/状态变（各语境的槽位口径见 §5 导航表的锚）。**破坏性动作（如录音丢弃）右槽须用破坏性提示文案**（如「丢弃」），不以中性词（如「结束」）代替——风险缓释靠键帽提示 +「BOOT = 放弃」总纲承担。

## 3. 设计语言（风格方向）

> ⭐ v2 修订核心（保留）：第一版设计被孩子评价"太正式"——太像"仪器面板"（等宽字体大时钟、规整表格线、整齐卡片）。本套设计要让它像一个"活的小伙伴住在里面"。

### 3.1 必须有的趣味性元素
1. **吉祥物角色「小伴」贯穿全局**：一个 **Hello Kitty 风格的极简猫咪**吉祥物（黑白剪影）——头部是**横向宽扁的圆（宽明显大于高，约 1.25:1）**，头顶两侧贴一对**扁小三角耳、与头部轮廓连成一体**（不悬浮、不竖长、不是河马/熊耳），小而低垂分开的圆眼、小小的鼻嘴，三根胡须、一条卷尾。它不只是图标，而是"住"在界面里的伙伴。**姿态集 = 六姿态**：
   - **日常**（首页常驻，随时段/日程换姿态与表情，如临近上课做「出门准备」状）
   - **聆听**（竖起耳朵/凑近听）· **思考**（抓头/头顶问号）· **播报**（张嘴说话/挥手）· **录音**（拿着话筒）· **提醒跳起**（像它发现了日程）
   - **没有低电打瞌睡姿态**（已砍——与「姿态随时段/日程变化」抢同一姿态通道）；保留的唯一低电信号 = 首页辅助条电池图标闪烁。姿态通道只服务日程/时段演出，不被系统状态抢占。
2. **手绘感与圆胖线条**：轮廓用粗圆线条（不是细直线框）、边框带轻微不规则感（手绘抖动）、卡片圆角加大、关键元素可微微倾斜/错位（1-2°，不要整齐划一）。
3. **拟物&拟人细节**：时间冒号做成两只眨眼的眼睛（静态即可）；温湿度用卡通造型而非仪表盘样式；**星星收集**——星星记录本每条配一颗星星图标，右上角 ×N 计数，录的越多星星越多（收集感）。
4. **装饰性涂鸦点缀**：页面角落少量星星/云朵/波浪线/小爱心（黑色剪影或网点），密度克制——点缀气氛，不抢信息。
5. **成就与奖励感**：讲完一段记录 → **「星星徽章·第 N 颗已入册！」**盖章演出（全屏定格居中、-8° 微倾定格 0.8 秒——例外构图，见 §5 导航表 P3 行）。

### 3.2 底层约束（不变）
- **童趣但克制**：8-12 岁，亲切可爱但不幼稚花哨（孩子已不喜欢"小宝宝风"）。趣味性来自"有角色、有表情、有惊喜感"，不来自满屏堆图案。
- **可读性分级**（v4 改，替代原「大字优先」；v7 按 requirements v1.69 落字号档）：字号随**信息优先级**分级、**不追求处处大字**——孩子一眼要看的关键信息（「接下来」事项与倒计时、星星计数、提醒大字）用大字；**正文类统一 16px**（P1 日程行 / P2 课表课名 / P3 列表与阅读正文），**阅读标题 20px**，**键帽条 / 辅助条 / 查字窗维持 14px 档**。CJK 1bpp 可读性下限已实测 = **14px**（NFR-READ-1；九档真机对照，2026-10-28 复测轮在案）——字号上调后每屏行数相应减少，靠分屏承接。
- **画布内字重单一（2026-10-28 human 看图反馈落约束）**：真机字体是**单字重 1bpp 位图**，屏幕上没有 700/900 这层「加粗」。**400×300 画布内的所有文字一律 400 常规字重**——母版不得用 font-weight 制造层次（12px 时代看不出来，16px 下会明显比真机胖）；层次只靠字号、留白与线框表达。文档壳（封面 / 导航 / 规格表 / 说明栏 / 图注）不在画布内，不受此限。
- **高对比黑白**：粗轮廓、大色块、清晰图标，避免细线和密集网点（RLCD 上糊）。趣味元素的线条也要粗、要大，缩小后不能糊成一团。
- **无渐变、无阴影、无彩色**：纯黑白 + 可选网点纹理。表情/姿态全靠黑白形状表达。
- **字体**：需要**中文字体**（优先圆体/胖黑体——比标准黑体更亲和；标题可用带手写感的字重），大字号下笔画不能糊。

### 3.3 教学字体红线（v3 确立；v4 措辞对齐：查字页 → 查字窗）
> ⚠️ **查字窗是教学面，字形就是教材**。孩子会照着屏幕写，示范字必须「标准规范」，绝不能教歪。

- **查字窗米字格里演示笔顺的示范汉字**（含笔画轨迹）：必须用**标准规范字体**（思源黑体/Noto Sans SC 或规范楷体），字形横平竖直、结构标准。**禁用站酷快乐体等手写/趣味字体**，禁用手写抖动、禁止倾斜（不用 tilt）。
- **拼音、部首、笔画数、组词等伴随文字**：**可以继续用可爱趣味字体**——红线只针对米字格里那个会被孩子照着写的示范字形。
- 其余页面（P1/P2/P3）的标题、装饰字、涂鸦可继续用趣味字体——红线只针对"教写字的示范字形"。
- 检验标准：把米字格的大字截图打印出来，家长一眼能确认"这个字的标准笔顺和结构是对的"，孩子照着写不会写出错别字或歪字。

## 4. 信息架构：3 个主页面循环 + 会话内窗口

设备共 **3 个主页面**，主屏按 BOOT 键循环切换：

```
P1 首页 → P2 课表 → P3 星星记录本 →（回到 P1）
```

- **没有第 4 页**（原 P4 查字常驻页已撤——查字改为**会话内弹出的专门窗口**）。
- 页面统一元素 = 底部键帽条（含 3 点页面指示器）；首页另有顶部小字辅助条（仅 P1 有）。
- 语音轮四态（聆听/思考/播报/提醒）**同一版式骨架 = 左小伴（各态 pose）· 右内容区**，不为单一态做特别设计。

## 7. 给设计师的提醒

- 这是**黑白墨水屏质感**的设备，想象"电子纸/Kindle"的观感，不是手机彩屏。
- **孩子说"太正式"= 太像仪表盘/办公软件。要让它像一个"活的小伙伴住在里面"**——有角色、有表情、会眨眼、会凑过来听。检验标准：把设计给孩子看，第一反应应该是"它好可爱/它在看我"，而不是"这是个闹钟"。
- 信息**宁少勿多**——孩子 + 小屏，一屏一个重点。
- 每个页面都要回答："孩子不看说明书，能看懂现在能干嘛吗？"（靠键帽条提示 + 图标 + 小伴的状态演出）。
- **字号 = 信息优先级的视觉表达**，不是全局大字口号（§3.2 可读性分级）。
- **字号下限纪律**：CJK 正文不得低于 14px（NFR-READ-1 实测下限）；正文档统一 16px，键帽条 / 辅助条 / 查字窗贴线 14px——低于 14px 即违例。
- **不要用「加粗」做层次**：真机只有单字重，画布内一律 400；想让信息更重，靠字号放大、留白隔离与线框，不靠 font-weight。
- **网点（dithering）全局口径待拍**——设计稿里先用得克制，拍板前别把网点当确定手段。
- 中文显示是主体，确保中文在大字号下清晰、友好。
- 趣味元素的线条在 400×300 低分辨率下不能糊：形状大、轮廓粗、细节少。
- **实现缺口须知**（真机上暂不存在、按全新做）：思考页、聆听态话语回显区、键帽条三槽与页点、电量真实值——详见 [PHASE1-DESIGN-INPUT.md](PHASE1-DESIGN-INPUT.md) §四。
