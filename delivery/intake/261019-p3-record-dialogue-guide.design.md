# P3 记录会话改造：对话式引导态 · companion 设计稿（T4，免冻）

> 状态 = 成形设计已获 human 批准（2026-10-19 brainstorming 会话逐段确认），待 `/triage-change` 跨面 intake 消费。本稿是讨论记录，非 canonical；正式修订由各面 loop 制品承载。

## 意图（human 原话要点）

P3「我要讲故事」现在是一个单独的聆听状态——孩子一直讲、AI 只在那儿听，讲完后才转写记下来。改成**对话式**：孩子说「我要讲故事」/「帮我记下来」后进引导态，AI 看故事讲到了哪里、引导式地跟孩子说「那下一步应该是什么」；等引导完、孩子说「讲完了」，再把整个过程中**小孩说的内容**整理并转写成一个故事。

## 已拍决策（human 逐项确认）

| # | 决策点 | 裁定 | 依据 |
|---|---|---|---|
| 1 | 归档内容与孩子原话的关系 | **忠实整理**：只用孩子自己说过的内容与事实，AI 只做去口水词、断句、分段、起标题，不换表达、不补情节 | 产品定位 = 星星记录本留住「孩子自己的话」；防 AI 编情节导致回看时不认账 |
| 2 | 适用范围 | **单一记录语境对话态**：P3 按 KEY 与两个触发词都进同一语境，引导策略随内容自适应（讲故事推情节「那然后呢」；日记/碎碎念轻提「还有呢」）；孩子说「别说话听我讲」时 AI 自然转为只听——LLM 语境行为，不加独立状态机 | 一种语境一套机制，心智最简单；双模式会让入口意图分类变成关键路径 |
| 3 | AI 开口引导的时机 | **停顿/卡壳才引导**：孩子讲着时 AI 闭嘴（切句只用于回显），仅在 ① 停顿超阈值（起步约 8 秒，待定、真机调优）② 孩子明示卡住 时轻推一把；引导语由 LLM 看已讲内容生成 | 每段接话会把故事切成一问一答碎片，且每段付一轮 ASR→LLM→TTS 延迟与成本；技术上最接近现有累积机制 = StoryAccumulator 加「卡壳计时器」，触发轻引导而非收尾 |
| 4 | 段一机制整体 | 认可：流程、引导语不进素材、收尾一次性整理、契约零改动预判 | 见下「机制」节 |

被否方案（留痕防回摆）：润色改写归档（稀释「孩子自己的话」）；双版本并存（原文+整理版双份存储/语义，Phase 1 偏重）；故事引导+记录纯录双模式；每段接话；按情节段落引导（「段落边界」LLM 实时判定机械上不可靠）；边讲边增量整理（贵且易跑偏，一次性整理的延迟由思考态盖住）。

## 机制（「记录语境对话态」，取代累积态）

仍是与闲聊对话正式分流的第二条聆听语义，但从「闭嘴累积」变「累积 + 卡壳轻引导 + 收尾整理」。入口不变（P3 KEY / 触发词 → 引导语「需要我帮你记点什么？」）。

1. **孩子讲**：VAD 切句 → STT → 右区回显（同现状）+ 追加进会话记录缓冲；AI 闭嘴。
2. **卡壳计时器**：每句讲完起约 8 秒计时；孩子接着说 → 重置；计时到 → 网关把目前累积的孩子的话发 LLM（带引导指令）→ 生成一句轻引导 → TTS 播报 → 继续聆听。
3. **引导语不是素材**：整理输入只取孩子说的话；AI 引导句、孩子中途提问与 AI 回答都不进故事——「提问也被记录」旧一刀切（2026-09-14 裁）随之废除，对话内问答天然被滤掉。
4. **收尾**：说「讲完啦/我说完了」→ 思考态（复用现有思考页，盖住整理延迟）；或再按 KEY 同效；BOOT /「讲错啦」= 取消丢弃（不变）。
5. **整理与归档**：网关把全程孩子的话一次性发 LLM（忠实整理指令）→ story MD → 走现有 `archive_story` 落盘、流水号、盖章演出、列表推送——归档下游不动。
6. **自动收尾**：连续引导 2 轮孩子仍无回应 → 视为讲完，自动走 4、5（取代现 120 秒纯静默超时；录音期提醒排队延后规则不变）。

## UI 与边界

- 录音态主屏骨架不变（REC 闪点 + 大时长 + 回显区 + pose-record）；气泡文案换对话语境口径（措辞归设计稿）。**AI 引导播报时不跳页**：停留记录会话屏、引导语 TTS + 换气泡文字；WF-F2-02 只加增补注记，不动四态通则。收尾后思考态（气泡可「我来整理一下…」）→ 盖章照旧。触 UI → 需求档 2 批次按流程派 uiux-author 出修订。
- **断网/断电**：记录缓冲在网关，断连即失（同现状，不扩本地暂存——介质禁令下故事缓冲属业务状态，只驻云端/RAM）；断网时记录语境不可用，NFR-OFF-1 已覆盖。
- **误收尾**：维持 v1.49 裁定不设恢复；旧「刚才那段是故事」挽回口径在闲聊语境（其他页）继续保留。
- **卡壳阈值**列 NFR 待定阈值，真机调优后立项拍数。
- **引导语护栏**（prompt 约束）：只基于孩子已讲内容提问，不提供情节选项、不代编——与忠实整理同一原则，防引导变 AI 主导写故事。
- **整理忠实性机判难点**（如实标注）：LLM 输出不能逐字断言，拟用固定转写 fixture + 事实点比对（输出不得含输入外实体）做机判兜底，忠实度抽检留人工。

## 验收种子（交 acceptance-author）

卡壳计时触发引导；引导语/问答不进归档；「讲完啦」→ 整理 → 列表新篇 + 盖章；BOOT 取消丢弃；引导 2 轮无回应自动收尾；整理忠实性（fixture 机判 + 人工抽检）。真机停顿手感走观感直修长环、闸链后补账。
