## 3. 摩擦与卡点（按痛感排序）

- **F1 · 判官 R1 抓到「同名字段的第二写面」——我的 census 只扫了一面就拟 canonical 形状**
  - **现象**：T1 拟把 `crossPackageBehaviors` 的 canonical 形状钉成 `{behavior, owner, note}`（从 8 个包面实例反推）；R1-F1 指出该字段**还作顶层键写在 workstream 的 `decision-coverage.json` 里**，形状为 `{topic, owner, note, carriedBy}`——键名不同、**多一个 `carriedBy`**，且 `owner ≠ carriedBy` 是活语义。
  - **根因**：我做的是「**从一个写面的实例反推形状**」，没做「**对同名字段做全写面 fan-out**」。危险在于：这类错误不会红——它产出的 canonical 会与仓内既有数据**并存**，直到某个下游按新定义解析 workstream 面才发现判错。R1 复核后还发现**我的修法方向也得改**（不是补一句说明，而是承接包判定必须收编两形）。
  - **证据锚**：§7 R1-F1；我复核的 verbatim = `delivery/workstreams/m1-home-qa/decision-coverage.json:116-141`（第 2 条 `:123-128`：`owner: 260915-m1-k3-voice-round-ui` / `carriedBy: 260915-m1-k4-reminder-overlay-unify`）；census 命令 `grep -rn "crossPackageBehaviors" delivery/workstreams/` → 2 处命中（现役 1 + 归档 1）。
- **F2 · 核验官 F1 抓到「显式落点指令被我读成追加」——FROZEN 写「置 `residual risk` 之前」，我 append 到了之后**
  - **现象**：FROZEN §2 T3 改法 1（`PROPOSAL.md:124`）原文「必列项**增一条**（**置 `residual risk` 之前**，逐字形态见下）」；落地首版把该 bullet 放在 `residual risk` **之后**（`dev-loop.md:248`）。核验官判 `verdict: FAIL(F1)`，并指出同量级落点偏差（§3-#2「⑤ 置于 ④ 之后」）已申报、此条未申报 = **该记未记**。
  - **根因**：改法文本里**两个动作并存**——「增一条」（追加语义）×「置 X 之前」（定位语义）；我在起草期写得够清楚，落地时却按「增一条」的直觉走，**把位置副词当成了修辞**。更值得记的是：**该偏差没有任何机器可判面**（fail-loud 不覆盖散文 bullet 的位次），漏掉它就只会让后来读者以为「必列项顺序随意」。
  - **证据锚**：核验官报告 F1（failingFile = `.claude/references/dev-loop.md`）；修后顺序 `:247` 未覆盖面申报 → `:248` residual risk（核验官复验亲跑确认）；我的教训已落 `architect-landing-summary.md` §3-#6。
- **F3 · 我的引据两处失准——「转述 + 凭印象归因出处」这对组合拳**
  - **现象**：① R1-F2：v0.2 写「该词在 `.claude/` 全域仅命中队列行与两份 ARQ 引文」——实测 `.claude/` **0 命中**，那两处在 `docs/ARCH-REVIEW-QUEUE.md`；② R1-F3：OQ1 把 closeout-chain 的**完整理由句**标成出处 `§6 留根②`（`:208`），实为 **T3 正文 `:126`**（§6 留根② 只是简记）。
  - **根因**：两条都不是判断错，是**引用工序错**——我在「写引据」时依赖的是记忆里的位置，而不是**逐行读一次**。这与在册「处方须实测复证」同族、但更细一层：**处方要复证，引文的出处同样要复证**（file:line 数字我核了，**归因句（谁在哪一节说的）我没核**）。
  - **证据锚**：§7 R1-F2 / R1-F3；更正后 verbatim = R1-F2 落 §2 T1 证据段「**该词在 `.claude/` 全域 0 命中**」；R1-F3 落 §4 OQ1（引 `260918-gov-review-closeout-chain-friction/PROPOSAL.md:126` 全句）。
- **near-miss（最险一刻）**：核验首轮那条 F1 —— **差一点就以「内容逐字正确、只位次相反」的形态带上 main**。它是最险的一种，因为：① 它**不红**（无机器判据覆盖散文位次）；② 它**已被我自己发现过一次同量级实例却没系统化**（同批 §3-#2 的「⑤ 置于 ④ 之后」我主动申报了，说明我意识到「位次是改法的一部分」，却仍在 T3 上违反了自己 FROZEN 的显式指令）；③ 若无独立核验，这条会永久留在 `dev-loop.md` 里，并向后来读者暗示「必列项顺序无所谓」——**这正是批② retro 记的「同一判据多处消费」病的散文版**。**没出事的唯一原因 = 核验官逐行核了锚清单与必列项顺序**，不是流程自己兜住的。
- **反向样本（本批值得记的正面）**：核验官自己也出了一条误判（ADVISORY A3：称 §3 旧语义未随落地）。我核后提出反证（`PROPOSAL.md:149` 早已是 `carriedBy ?? owner` 语义，旧短语只剩在 §7 的 append-only 判官记录 `:270`/`:286` 里），核验官**独立复核后主动撤回该条并在 verdict 文件里更正**。⇒ **「作者反驳判官」这条路在本批是通的、且被独立验证采纳**——独立结构不是单向的。

## 4. 优化建议（按 ROI 排序）

1. **改法文本里的位置副词，落地时按「承重指令」逐词核**：治 F2 · 载体 = **ARQ 收件箱（登记新条）**，落点候选 = `landing-fidelity-check.mjs --preflight` 增一类探针（扫 §2 各 T 改法段里的「置 X 之前 / 之后 / 之前一位」类方位短语，生成 landing 时的**逐条定位 checklist**），或最小版 = `track-b-verifier-brief.md` 六项清单第 1 项加一句「显式方位短语逐条核」· 预期收益 = 本批唯一 FAIL 即此条，且它不可机判、只能靠「有人特意核」——**把它变成核验清单的显式一项，成本近零**。
2. **拟 canonical 形状 / 枚举前，先对同名字段做全写面 fan-out census**：治 F1 · 载体 = **ARQ 收件箱（登记新条）**，落点候选 = `gov-arq` skill 或 PROPOSAL 起草 checklist 加一条硬项（「凡拟 canonical 形状 / 白名单 / 枚举 → 先 `grep -rn <字段名> .` 全仓 fan-out，逐写面核形状与语义」）· 预期收益 = 本批 ≈1/3 的子 agent 消耗（R2 返工）直接省掉；这条与在册「处方须实测复证」是同族纪律的**反向应用**（那条治「照抄处方前先证」，这条治「自拟定义前先查」）。
3. **引据的「归因句」与 file:line 同标准核**：治 F3 · 载体 = **ARQ 收件箱 / 或并入「citation 候选域」下一批** · 落点 = PROPOSAL 起草 checklist 的引据条补半句（「出处不仅是行号，还有**谁在说**——逐行读一次再落笔」）· 预期收益 = 本批两条 NIT 全属此类，起草期多花 2 分钟、省一轮 NIT 往返。
4. **本批无新增流程机制**：三条改法均落在既有 references / 约定面，零新门、零新脚本面——**这是「拆小批」策略的第二个实证**（第一个是批①）。建议随 §1 的 ROI 陈述一并交 `/loop-retro` 观察：本批是波次里往返最多的一批，但两次往返都换回了实体修正，**不构成对拆小批的否定**。

## 5. 一句总结

**成本** ≈54 min 挂钟（子 agent 实测 20.6 min + 主线程 ≈33 min〔推〕）、子 agent tokens ≈61.3 万（最大值口径，判官两轮占 67%）、human 触点 **2 次**（立项 ack + OQ 裁决，合并门前零升级）、制品 4 件齐（PROPOSAL + landing-summary + landing-verdict + retro）；**对照**：比批①/批② 往返多一轮、比 260918 四批小。**最险一刻** = 核验首轮那条位次偏差（内容对、位次反、无机器判据、差点带上 main）。**保险丝判定：两方独立结构（判官独立 + 核验官独立）接住了作者偏差——而且是三向都发生过**：判官接住 drafting 期的事实面缺口（F1 第二写面）、核验官接住 landing 期的保真缺口（F2 位次）、**主线程接住核验官自己的误判（A3 误读）并经其独立复核撤回**。最值得带走的一条：**「我把位置副词当修辞」和「我从一个写面反推 canonical」是同一类病的两个面——都是「看到一处就当作全部」；而这两处恰好分别被下两环各抓一次**——说明本仓的独立结构不是形式，它在真起作用。
