## 二、本轮需求变更 → 设计影响（按页面/状态组织）

### P1 首页（常显页）——**重心整体重排，改动最大**

| 变更 | 设计影响 | 出处 |
|---|---|---|
| 常显页要回答的是「**接下来我该干嘛**」，不是「现在几点、屋里多少度」 | 主体 = 接下来的日程 + 到点提醒；**时间/日期/温湿度/电量降为辅助信息**（小字、收进一条辅助带），不与日程抢视觉重心 | requirements §1 设备定位（v1.4） |
| 常显页要有**趣味演出与互动点缀**，不能是冷冰冰的待办清单 | 小伴**常驻**首页并随时段/日程换姿态与表情（如临近上课做「出门准备」状）；允许小彩蛋。**趣味与互动是常显页的构成部分，不是事后装饰**（原「点缀」定位已升格为构成原则） | requirements §1、§4 趣味性条目（v1.4/v1.5） |
| 线框已重排（WF-F1-01） | 新布局：顶部小字辅助条 → 主区左侧小伴、右侧「接下来」列表（**最近一项最醒目 + 倒计时**）→ 底部全局键帽条。原「☀ 晴 适合户外活动」天气行**已删**（孩子不在乎天气）；页内「[按一下 KEY 说话]」提示行**已删**（v1.21——语音提示归键帽条左槽「KEY 说话」，页内不重复画，P2 同口径） | requirements §3 WF-F1-01（v1.5/v1.21） |
| 布局优先级已定 | **接下来（最近项+倒计时）> 小伴演出 > 时间 > 温湿度**——原「时间 > 接下来 > 温湿度」作废 | S-F1.1 补充规则（v1.5） |
| 辅助条加**联网小标** + **图标前置**（v1.17） | 辅助条 = `📶 10:24 星期三 6月26日 🌡22°C 💧45% 🔋85%`：📶 联网打头、每项带小图标——起因 = 湿度 45% 裸数字挨着 🔋85% 易被当成电量。各小图标（📶/🌡/💧/🔋）需 1bpp 资产设计；联网图标链路已实现（基座状态栏每 10s 刷，断网自动变 **WiFi 斜杠断网态**、另有强/中/弱三档信号，S-F1.1 AC4 已补写），电量数字真机当前取不到（见 §四缺口表） | requirements WF-F1-01、S-F1.1 AC1（v1.17） |

> 待设计决定：倒计时贴纸的视觉形态、小伴在首页的占位大小与姿态触发规则（时段驱动 vs 日程驱动）、明日预告的呈现层级。

### 语音轮演出（需求侧现存四态：聆听 / 思考 / 播报 / 提醒；低电已砍）

> **线框已补（v1.22~v1.24）**：WF-B-01 聆听 / WF-B-02 思考 / WF-B-03 播报 / WF-B-04 提醒，四张都在 requirements §2.2 状态表后。**版式通则（v1.24 human 裁）：四态同一版式骨架 = 左小伴（各态 pose）· 右内容区**，仅 pose 图标与内容不同，不为单一态做特别设计——重做设计稿时以这四张为结构基准，美术表现（小伴姿态、气泡、问号、声波条的画法）由设计定。

| 状态 | 变更 | 设计影响 | 出处 |
|---|---|---|---|
| **聆听中** `state-listening` | 新增**话语回显区** | 除现有三层冗余反馈（竖耳 pose-listen / 麦克风 / 气泡「我在听！」）外，**孩子说的话要逐句回显在标识下方**，回显区可滚动、超屏高滚出。目的 = 孩子能确认「它听清了没」 | requirements §2.2（v1.11）、WF-B-01（v1.22） |
| **思考中** `state-thinking` | 定进入时机 + **真机从未弹出过** | 进入时机 = **孩子说完这一句**（服务端切句完成/音频上行结束），状态切换与页面弹出**同一时刻**；收到回复开始播报即离开；等待超 4 秒先开口安抚。⚠️ 这是**全新要做的页面**，不是改现有页面——MVP 的渲染接线缺失，真机上思考页从来不弹（详见 §五） | requirements §2.2（v1.12）、WF-B-02（v1.22）、arch §3.1 |
| **播报中** `state-speaking` | 无变更（v1.22 补线框） | 维持 pose-talk + 声波条 + 文字同步上屏；**这张就是「问答框」形态**——百科问答、语音问课表的答复文字都在这个区上屏（长文滚动） | requirements §2.2、WF-B-03（v1.22） |
| **打断停播** | **语音喊停不纳入 Phase 1**，打断只有 KEY 单击 | 播报态**不要**做「开口即停」的视觉暗示；键帽条 KEY 短语应表达「按一下停」 | requirements §2.1/§2.2（v1.7） |
| **提醒弹窗** `state-reminder` | **不单独设计，与语音轮同骨架**（v1.24） | ~~弹窗白底 + 粗黑描边 + 纯黑硬投影~~（v1.13 形态）**已作废**——提醒与聆听/思考/播报同一版式（左小伴 pose-jump · 右大字事项+时间，WF-B-04），网点压暗问题随之消解（整屏态无背景层级问题） | requirements §2.2（v1.24）、WF-B-04 |
| **提醒弹窗** | BOOT 语义写明 | **BOOT = 关弹窗回原页、不翻页**（v1.39 隔离：覆盖层内 BOOT 不翻页——v1.13「照常翻页」旧裁定翻转）；KEY = 关闭回当前页。键帽条右槽文案随之改「BOOT 关闭」类 | requirements §2.2、S-F1.4 AC2（v1.13 定 / v1.39 翻转） |
| **低电打盹** ~~`state-sleepy`~~ | **已砍（2026-09-13）** | **不要设计小伴睡姿演出**（pose-sleep + 月亮 + zZZ 整套作废）。理由：① human 判无意义；② 与「小伴姿态随时段/日程变化」抢同一姿态通道、互相覆盖；③ 该演出真机从未出现（活侧零调用者）。**保留的唯一低电信号** = P1 首页辅助条电池图标每秒闪烁、充电即停（已实现且有验收 P1-A4，归 S-F1.1 AC3）——设计上只需保证辅助条电池图标有「闪烁/灭相」两种画法 | requirements §2.2 已删行、S-F1.1 AC3、§8 已砍清单（v1.14） |

## 三、待 human 拍板的设计相关未决项

1. **网点（dithering）全局口径**：提醒弹窗的网点问题已随 v1.24 消解（弹窗形态作废、改整屏态同骨架，无背景可压暗）。设计稿里网点还有其它用法——腮红（d12 微点阵，brief 称之为「本套设计里网点的招牌用法」）、故事保存勋章背景（d25）、查字窗「未写笔画」的轮廓、聆听态指示点背景（d50）。**是否全局禁用网点**尚未裁定；若全局禁用，requirements §4「可用抖动(dithering)模拟灰度层次」一句要相应收紧，腮红等元素需另找黑白表达法。
2. ~~「故事记录」改名~~ **已拍（v1.26）**：P3 页名 = **星星记录本**、F2 = **星星记录**、内容口径 = 孩子讲给小伴记下来的一切（故事、日记、碎碎念）；「故事果」资产改名**星星**（列表条目图标、×N 计数、盖章演出「星星徽章·第 N 颗已入册！」）。**设计侧待办**：brief 里的「故事果」收集资产名、P3 页面线框（含星星图标/贴星星演出画法）归设计稿重做。
3. **回显区与播报文字是否复用同一区域**：聆听态的「话语回显区」（WF-B-01）与播报态的「文字同步上屏」（WF-B-03）是否共用一块文字区，待设计定。

## 四、Phase 1 已知实现缺口（设计需知道哪些是「新做」）

这几项不是「改现有页面」，而是**真机上目前根本不存在**，设计时按全新页面/元素对待：

| 缺口 | 现状证据 | 影响 |
|---|---|---|
| **思考页真机不弹** | `lang_config.h` 无 thinking 状态文案；活侧 `LcdDisplay::SetStatus` 只映射 LISTENING/SPEAKING/STANDBY 三态；`KVST_SCENE_THINK` 场景码与姿态资产已备且验收过，但**零调用者**；小智 DeviceState 枚举本无 thinking 态 | `state-thinking`（pose-think + 飘问号）需从零接线，Phase 1 修复项。机制细节见 arch §3.1 |
| **聆听态话语回显未实现** | 回显链路本身已通（网关 ASR 切句 → WS `stt` 消息 → `SetChatMessage("user")` 上屏，MVP 真机已实测），但**没有专属回显区**，走的是小智原生聊天文本位 | 回显区的版式（位置、字号、滚动行为、与三层反馈的布局关系）需新设计 |
| **键帽条三槽布局与页点未实现** | `bottom_bar_` 已常驻（全宽、min-height 48px，设计规格为 38px），但内部**只有一个居中 label**（文案随态联动：说完啦/不等了/打断/知道了/叫醒它）；**三槽布局、页点、BOOT 提示、`[KEY]`/`[BOOT]` 键帽图形全部未做**（全仓搜「页点」零命中） | 需按 v3 §06 `comp-keybar` 规格重做该条：左 KEY 提示 / 中 3 页点（v1.36 页循环 4→3）/ 右 BOOT 提示，并实现「覆盖层（提醒弹窗/查字窗/语音轮演出）隐藏中槽页点、左右槽照常」的随态切换 |
| **电量百分比真机取不到**（v1.17 登记） | 硬件有电池 ADC（官方 Demo `03_ADC_Test`：ADC1_CH3=GPIO4 分压已验证），但固件三处未接线：板类 ADC 成员是死变量、无 `GetBatteryLevel` override、渲染节点无电池注入缝——真机电量**恒显示 100%**，低电闪烁（S-F1.1 AC3）真机不触发 | 辅助条电池图标与数字按「会动」设计（五档电量 + 充电态 + 低电每秒闪的灭相）；接线是固件活，不影响版式 |
