# 小伴（KidPal）— ESP32-S3 儿童学习伙伴 · 初步 Spec

> 版本：v0.1（草稿，待 brainstorm 补齐）
> 目标用户：8–12 岁小朋友
> 形态：ESP32-S3-RLCD-4.2 作为 Client 端，云端（Aliyun + OpenClaw）作为服务端大脑

---

## 1. 背景与目标

给 8–12 岁小朋友做一个随身学习伙伴。设备本地做「感知 + 显示 + 交互」，云端做「理解 + 生成 + 存储」。
三大核心功能：

1. **课表/日程助手** — 记录课表与培训班时间，支持查询与提醒。
2. **故事记录** — 听孩子口述故事，实时转写并归档保存，可回听/回看。
3. **查生字** — 孩子问「某个字怎么写」，设备把汉字的**笔顺/写法**清晰显示出来。

## 2. 硬件能力盘点（依据本地官方 Demo 实测确认）

| 模块 | 型号/配置 | 说明 |
|---|---|---|
| 主控 | ESP32-S3-WROOM-1-N16R8（双核 240MHz） | Wi-Fi + BLE5，512KB SRAM + 384KB ROM，**16MB Flash + 8MB PSRAM** |
| 屏幕 | **RLCD 反射式，ST7305 驱动，400×300 横屏(300×400竖)，1bpp 单色** | 4.2寸。SPI(SCK11/MOSI12/DC5/CS40/RST41)。无背光靠环境光，越亮越清晰，暗处不可见(本板文档未列前光→大概率无)，超低功耗可常显。一帧 400×300÷8=15KB。**刷新快(~45-70 FPS)，可动画/滚动/实时刷新**。ST7305 支持局部窗口更新+低功耗模式 |
| **按键 ×3** | **KEY（自定义）、BOOT（GPIO0）、PWR（电源）** | KEY=自定义功能键；BOOT=按住上电进下载模式/平时可自定义；**PWR=长按关机/单击开机**。实际可用功能键=KEY+BOOT 两个，PWR 专管开关机。multi_button 支持单击/双击/长按 |
| 触摸屏 | **无** | 交互全靠按键 + 语音 |
| 音频输入 | ES7210 ADC + **双麦克风阵列** | 支持降噪/回声消除，可做近场/远场语音识别与唤醒（当前用"按一下启动会话"） |
| 音频输出 | ES8311 codec + PA（MX1.25 2PIN 扬声器接口） | I2S 放音，可播放提示音/语音 |
| RTC | PCF85063（I2C）+ **RTC 独立备用电池座** | 走时提醒，主电/RTC 独立续航，掉电保持 |
| 传感器 | SHTC3 温湿度 | 辅助（可显示环境温度湿度） |
| 存储 | Micro SD 卡槽（FAT32）+ 16MB Flash | 本地缓存录音、字库、课表 |
| 电池 | **18650 锂电池座 + 充放电管理** | 便携；ADC 测电压电量；CHG充电/WRN反接指示灯 |
| 扩展 | 2×8 排母(2.54mm) + USB/UART/I2C/GPIO | 可扩展前光等 |

> 关键约束（已据官方文档修正）：
> - **400×300 单色 1bpp**：UI 用黑/白两色 + 抖动(dithering)模拟灰度。
> - **刷新快（~45-70 FPS）**：与普通 LCD 相当，**可做流畅滚动、动画、笔顺动态演示**——非墨水屏那种慢。这解放了 UI 设计。
> - **反射式无背光**：暗处不可见（本板大概率无前光，待确认），阳光下极佳、超低功耗、可常显「今日日程」。
> - **图形库**：沿用**小智自带 LVGL**（单色模式），笔顺用 `lv_canvas` 绘制，不重写显示层。（u8g2 官方虽主推单色，但换它需重写显示层，基于小智改则沿用 LVGL 更省事。）
> - ST7305 支持局部窗口更新，可按需优化功耗。
> - 语音是主要输入方式（孩子打字不便），配合少量物理按键。
>
> 环境硬要求：arduino-esp32 **v3.3.0+**，U8g2 **v2.36.19+**（才含 ST7305 300×400 支持）。

## 3. 系统架构

### 3.0 顶层定位（已定 ✅：OpenClaw 编排层 + 板子终端）

> 这是与用户对齐后的核心定位，统领整个架构。

```
【ESP32 板子】= 终端（"会说话的显示器"）
   只负责：麦克风收音、扬声器放音、屏幕显示、按键交互
   ❌ 不理解业务、❌ 不存数据、❌ 不做智能

【OpenClaw】= 编排层 + 主 Agent（大脑 + 记忆 + 工具）
   负责：听懂(ASR)、理解意图(DeepSeek)、执行功能、记忆存储(MD 文件)、回复(TTS)
   ✅ 所有数据、逻辑、记忆都在这里
```

**核心原则**：板子是个"哑终端"，一切智能与记忆在 OpenClaw。板子通过一套**约定的数据格式**接收"屏幕要显示什么"，只负责渲染。课表存成 MD、故事存成 MD、生字笔顺由 OpenClaw 按格式输出——板子拿来就画。

---

### 3.0.0 服务端架构（已定 ✅：薄桥 shim，OpenClaw 自带 OpenAI 兼容 API）

> 关键发现：OpenClaw 网关自带 **OpenAI 兼容 HTTP API（`POST /v1/chat/completions`）**，跑的是完整 agent（意图理解/多轮会话/读课表MD/存故事/查字/记忆/工具调用全包）。**业务网关、CRUD、意图层全部不需要自研**。

```
【ESP32 设备】(家里)
   │ 设备 token（弱权限，丢了不致命）
   ▼ 公网（wss，二期上 TLS）
【薄桥 shim】FastAPI ~200 行，唯一公网入口
   POST /v1/asr    音频 → faster-whisper → 文字
   POST /v1/chat   文字 → 调本机 OpenClaw /v1/chat/completions → 回复+显示JSON
   POST /v1/tts    文字 → edge-tts → mp3
   GET  /v1/alerts 设备轮询提醒（OpenClaw cron 写文件，shim 读出）
   │ loopback + 真 token（真 token 不出内网）
   ▼
【OpenClaw 网关】大脑 —— 现有能力，零新业务代码
```

**砍掉**：自研业务网关、CRUD 接口、会话/意图层（DeepSeek+多轮对话自带）。
**保留（极薄）**：音频转换（ASR/TTS 必须有 HTTP 口子）+ 设备鉴权 + 提醒轮询。

**MVP 与二期边界**：
- MVP 走 **同步 HTTP**（整段：说话→ASR→DeepSeek完整回复→TTS→播放）。简单可靠，延迟偏高（数秒）可接受。
- **语音喊停靠本地**（AEC+VAD 本地停播，不依赖云端取消生成）。
- 二期升级：**WebSocket 流式通道**（边说边识别、边生成边播、可中途取消），替换同步 HTTP。

### 3.0.2 待与 OpenClaw 对齐的关键格式

#### ✅ D3 笔顺数据格式（已定稿，OpenClaw 已实测跑通）
数据源：**makemeahanzi**（HanziWriter 同款开源数据，9574 字 / 32MB，已下载到服务器 `kidpal/chardata/`）：
- `dictionary.txt`：拼音、部首、结构（如 ⿱甬力）、笔画数、释义
- `graphics.txt`：每笔一个 SVG path + medians 骨架点

**单字 JSON（实测"勇"字约 2KB）**：
```json
{
  "type": "char",
  "char": "勇",
  "pinyin": "yǒng",
  "radical": "力",
  "strokeCount": 9,
  "strokes": ["M 547 677 Q ...", "..."],
  "medians": [[[x, y], ...], ...],
  "structure": "⿱甬力",
  "meaning": "勇敢；有胆量"
}
```
- `strokes`：9 条 SVG path（1024×1024 坐标系），用于逐笔填充显示字形。
- `medians`：每笔骨架中线点序列，"笔尖"沿它移动做写字动画（HanziWriter 同机制）。

**板子端渲染要点**（确定性，无技术风险）：
- **坐标变换**：1024×1024 → 400×300。注意 makemeahanzi Y 轴朝下且字形偏上，需翻转+偏移。
- **SVG path 解析**：路径含 M/Q/L/Z（二次贝塞尔）。板子端用轻量解析器把贝塞尔离散成点，LVGL `lv_canvas` 逐点绘制，或简化为折线逼近（1bpp 下视觉差异小）。
- **1bpp 光栅化**：矢量轮廓 scanline 填充成黑白位图，逐笔叠加显示。

#### 🔵 E1 统一响应格式（已出草案，见 [docs/contracts/interface-contract.md](../../contracts/interface-contract.md)）
核心思路：OpenClaw `/v1/chat/completions` 返回纯文本，约定在回复末尾用 ` ```display ` 代码块嵌入显示指令 JSON，shim 切分两路——正文送 TTS 播放，display JSON 下发板子渲染。
- 顶层：`{view, data, speech_hint?}`，`view` 决定板子切哪页。
- view 类型：`char`(查字/接D3) / `schedule`(课表) / `story_list` / `story_text` / `text`(纯文本) / `home`(回首页) / `control`(控制:end_session等)。
- 对 OpenClaw 要求：system prompt 约束 DeepSeek 始终按此格式回复（需实测格式遵循度）。

#### 🔵 B1 课表 MD 结构（已出草案，见 [docs/contracts/interface-contract.md](../../contracts/interface-contract.md)）
`schedule.md` = YAML frontmatter（提醒提前量/时区/孩子名）+ Markdown 表格：
- **每周固定课表**（星期/时间/课程/地点/备注）
- **一次性安排**（日期/时间/事项/地点/备注）
- **学校课程表**（可选）
DeepSeek 直接读 MD 按"今天星期几/当前时间"筛选查询；cron 定时扫描到点写提醒文件（`alerts/pending.json`，shim `/v1/alerts` 读出下发）。
录入：家长 QQ 对 OpenClaw 说，或直接改 MD。

### 3.1 技术基础：基于"小智"(XiaoZhi) 二次开发 ✅（已定）
官方 Demo 已含**小智 V2.1.0 对本板的完整移植**（`03_XiaoZhi/XiaoZhiCode_V2.1.0`，板级目录 `main/boards/waveshare-s3-rlcd-4.2/`）。它是 ESP-IDF + C++ 大型工程，已集成：
- **ESP-SR AFE 音频前端**：唤醒词(WakeNet) + **AEC 回声消除** + **VAD 语音活动检测**（一个引擎全包，跑在核1，内存放 PSRAM）
- **全双工音频**：ES8311(放)+ES7210(录)，24kHz，`AUDIO_INPUT_REFERENCE=true`（AEC 用播放信号做参考）
- **按键即对话**：BOOT 单击 = `ToggleChatState()` 切换对话状态（正是"按一下启动会话"模式）
- RLCD 显示驱动（custom_lcd_display）、Wi-Fi、Opus 编解码、MCP 工具框架、LVGL

**我们基于它改：换后端（接 Aliyun+OpenClaw）+ 重做 UI（4页结构）+ 加课表/故事/查字业务。** 不用从零整合音频/AEC/显示底层。

### 3.2 端云职责划分（已修正：本地做实时音频处理）
> 关键修正：全放云端会有"gap"——喊停/打断要求即时响应，等云端来不及。**实时的音频信号处理必须放本地 ESP-SR；理解语义才放云端。**（这正是小智架构）

| 能力 | 位置 | 说明 |
|---|---|---|
| **AEC 回声消除** | **本地**（ESP-SR AFE） | 边放音边录音消回声，实时性 |
| **VAD 语音活动检测** | **本地**（ESP-SR AFE） | 检测孩子插话/喊停，即时 |
| **唤醒词检测** | **本地**（ESP-SR WakeNet） | 二期唤醒用 |
| **喊停/打断检测** | **本地**（AEC+VAD 检测到人声即停播） | 必须即时，不等云端 |
| **会话管理**（按一下启动/超时关/结束关） | 本地状态机 | 基于小智 ToggleChatState 改 |
| **ASR（自由语音→文字）** | **云端**（faster-whisper，经 shim `/v1/asr`） | 开放语句本地识别不了 |
| **意图理解/对话/纠正** | **云端**（OpenClaw+DeepSeek，`/v1/chat/completions`） | 重智能，含"别讲了/不对"等控制指令理解 |
| **TTS 语音合成** | **云端**（edge-tts，经 shim `/v1/tts`） | 晓晓/云希童声 |
| **课表/故事/查字业务+存储** | **云端**（OpenClaw，MD 文件） | |

### 3.4 核心请求链路（以查字为例）
```
孩子按一下 KEY（或二期喊唤醒词）→ 设备进入对话态，本地 AFE 开始聆听
  → 孩子说"勇敢的勇怎么写" → 本地 VAD 检测说话结束
  → 音频经 shim /v1/asr（faster-whisper）转文字 → 经 shim /v1/chat 调 OpenClaw
  → OpenClaw/DeepSeek 判意图=查字，提取"勇"，查 makemeahanzi 组笔顺 JSON
  → 回复正文经 shim /v1/tts（edge-tts）生成语音，display JSON 下发板子
  → 板子：屏幕画"勇"+笔顺演示，扬声器播读音
  → 若 AI 讲太长，孩子喊"别讲了"→ 本地 VAD 检测到人声→立即停播→送云端判为"停止"
```
**设备固件保持"笨"而轻，所有 AI 能力都在服务端**，便于随时升级模型而不动终端。

## 4. 功能需求

### F1 课表 / 日程助手
- F1.1 录入课表：家长/孩子通过语音或 App（待定）录入课程与培训班时间。
- F1.2 查询：孩子问「今天下午有什么课？」「明天几点上钢琴？」→ 语音/屏幕答复。
- F1.3 提醒：到点前 N 分钟，屏幕显示 + 提示音/语音提醒（基于 RTC，离线也能提醒）。
- F1.4 常显主屏：显示当前时间 + 今日接下来 1–2 件事（利用 RLCD 常显优势）。

### F2 故事记录
- F2.1 一键开始/结束录音（孩子说故事）。
- F2.2 音频上传云端 → ASR 转文字 → 归档（标题、时间、正文）。
- F2.3 列表查看历史故事（屏幕列表 + 可回听原音 / 看文字）。
- F2.4（可选）云端对故事做「润色/起标题/配小结」。

### F3 查生字
- F3.1 孩子语音提问：「『勇敢』的『勇』怎么写？」
- F3.2 云端解析目标汉字 → 返回该字的**笔顺分解 + 字形数据**。

## 5. 交互与 UI 设计（400×300 黑白 1bpp RLCD 约束）

### 5.1 设备定位与应用过程
它**首先是个"常显的信息牌"，其次才是语音交互设备**。平时 90% 时间常显在桌上/书包旁，孩子瞟一眼就知道现在几点、待会干嘛、屋里多少度；孩子有事了才按键交互。

```
【常显状态】屏幕常显（反射屏不耗电）：时间 + 今日日程 + 温湿度 + 电量
【交互状态】按一下 KEY 启动会话（免提说话）/ 按 BOOT 翻页 → 设备响应 → 超时或按键自动回首页
```

### 5.2 语音交互模型（已定：按一下启动会话 + 语音喊停）
**核心：按键只是"激活开关"，一旦激活进入免提会话，无需一直按住。**

```
【常显】屏幕常显信息牌（时间/日程/温湿度）
   │ 按一下 KEY（≈喊了唤醒词）
   ▼
【对话态】设备提示音+屏幕显示聆听中，本地 AFE(AEC+VAD) 启动
   │ 孩子说话 → VAD 检测停顿 → 送云端理解 → 设备回应 → 继续聆听
   │ 可连续追问，不用每次按键
   ▼
【结束】三种任一：
  ① 超时：60 秒无语音 → 自动关闭，回常显
  ② 孩子说"拜拜/不用了" → 云端判为结束意图 → 关闭
  ③ 再按一下 KEY / BOOT → 手动关闭
```

**语音喊停（MVP 必做）✅**：AI 播放中，本地 AFE 持续跑（AEC 消回声 + VAD 检测人声）。
- **行为定义**：AI 播放中孩子**一开口（不管说什么）AI 立即停下并聆听**——既是喊停又是自然插话。
- 本地 AEC+VAD 检测到人声盖过播放声 → **立即停播（不等云端）** → 把孩子这段送云端 ASR → 云端判断："别讲了"→确认停止；"不对，是勇敢的勇"→纠正重答。
- 依赖 AEC 效果，音量过大/混响强时可能误触发或漏触发，**需实测调阈值**（最大不确定点）。
- 兜底：KEY 单击 = 随时打断停播（100% 可靠）。

**为什么本地做**：全放云端有"gap"——喊停/打断要即时响应，等云端来不及。实时音频处理（AEC/VAD/喊停）放本地 ESP-SR，语义理解放云端。

**二期唤醒词**：硬件已支持（双麦+ES7210），小智已集成 WakeNet。届时按一下 KEY 可替换为喊唤醒词，其余会话逻辑不变。

### 5.3 按键定义（3 键，无触摸）
| 键 | 单击 | 长按 | 备注 |
|---|---|---|---|
| **KEY**（主功能键） | **启动/结束会话**；对话中=打断停播；列表中=确认/下一项 | 回首页 | 核心交互键 |
| **BOOT**（辅键） | **切换页面（循环）**；对话中=也可结束会话 | 配网/特殊 | 小智默认 BOOT=ToggleChatState，可复用 |
| **PWR**（电源键） | 单击开机 | 长按关机 | 电源管理 |

核心逻辑：平时 BOOT 翻页浏览；有事按一下 KEY 进入语音会话（免提连续对话）；说完自动/手动结束回首页。对话中再按 KEY 可打断。

> 注：小智默认用 BOOT 做 ToggleChatState。我们可改为 KEY 主司对话、BOOT 主司翻页，更符合"KEY=主要交互"直觉。最终键位在 UI 联调时定。

### 5.4 页面结构（4 页循环）
```
        BOOT 单击 → 切下一页（循环）
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ P1 首页  │→ │ P2 课表  │→ │ P3 故事  │→ │ P4 查字  │→┐
│时间日程  │   │本周课程  │   │我的故事  │   │笔顺演示  │ │
│温湿度    │← │         │← │列表     │← │         │←┘
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

- **P1 首页**（常显默认）：时间+日期+温湿度+今日接下来日程+电量。按一下 KEY 启动语音会话；到点自动弹提醒（亮屏+提示音）。
- **P2 课表页**：本周课程表格。KEY单击切"今天/明天/本周"；语音问"明天有什么课"→播报+高亮。
- **P3 故事页**：我录的故事标题列表。KEY单击光标下移选择，KEY双击播放选中；语音说"我要讲故事"→进入录音（显示●录音中），说完自动/按键停止并上传。
- **P4 查字页**：超大字形+拼音+笔画+笔顺演示。语音说"勇怎么写"→整屏显示；KEY单击播笔顺动画（逐笔写出）；KEY双击重播；继续说"勇是什么意思"→释义组词。

## 6. 端云接口

### 6.1 薄桥 shim 接口（唯一公网入口，与 OpenClaw 对齐后定稿）
| 接口 | 方向 | 内容 |
|---|---|---|
| `POST /v1/asr` | 端→shim | 上传音频（Opus）→ faster-whisper → 返回文字 |
| `POST /v1/chat` | 端→shim | 文字 → 调 OpenClaw `/v1/chat/completions` → 返回回复正文（TTS用）+ display 显示指令 JSON |
| `POST /v1/tts` | 端→shim | 文字 → edge-tts → 返回语音（mp3/Opus） |
| `GET /v1/alerts` | 端→shim | 设备轮询课表提醒（OpenClaw cron 写文件，shim 读出下发） |

> 业务接口（课表 CRUD、故事、查字）**全部不需要**——由 OpenClaw 完整 agent 经 `/v1/chat/completions` 统一处理，结果通过 display 指令下发。详细契约见 [docs/contracts/interface-contract.md](../../contracts/interface-contract.md)。

### 6.2 设备↔shim 显示指令（E1）
OpenClaw 回复末尾 ` ```display ` 块嵌入 JSON，`view` 决定板子切哪页渲染：
`char`(查字/接D3笔顺) / `schedule`(课表) / `story_list` / `story_text` / `text` / `home` / `control`(end_session等)。

### 6.3 待定

## 7. 关键技术决策

### 已定 ✅
1. **顶层定位**：**OpenClaw 作编排层+主 Agent（大脑/记忆/工具），板子只作"会说话的显示器"终端**。所有数据/逻辑/记忆在 OpenClaw（课表存MD、故事存MD、笔顺由OpenClaw按格式输出）；板子只收音/放音/显示/按键。
2. **技术路线**：**基于小智(XiaoZhi V2.1.0) 二次开发**（官方已移植本板，含 AFE唤醒+AEC+VAD、全双工音频、显示、Wi-Fi、Opus、LVGL）。换后端接 Aliyun+OpenClaw + 重做 UI + 加业务。
3. **端云划分**：本地做**实时音频处理**（AEC/VAD/唤醒/喊停检测/会话管理），云端做**语义理解**（ASR/意图/对话/TTS/业务）。
4. **服务端架构**：**薄桥 shim（FastAPI ~200行，唯一公网入口）+ OpenClaw 自带 OpenAI 兼容 API**。OpenClaw 网关有 `POST /v1/chat/completions`（默认关闭，开启即可），跑完整 agent（意图/会话/读课表MD/存故事/查字/记忆/工具全包）。**业务网关/CRUD/意图层零自研**。shim 只做 ASR/TTS HTTP 口子 + 设备鉴权 + 提醒轮询。
5. **OpenClaw 部署**：阿里云成都 ECS（公网 ws://8.137.91.16:18789 已验证通，内网 172.26.11.60）。shim 与 OpenClaw 同机，loopback 调用，真 token 不出内网。
6. **ASR/TTS**：放 OpenClaw 机器（faster-whisper + edge-tts，待装），经 shim `/v1/asr`、`/v1/tts` 暴露。
7. **语音交互**：**按一下 KEY 启动会话**（≈唤醒词体验），免提连续对话，60秒超时/说"拜拜"/再按键 结束。二期加 WakeNet 唤醒词。
8. **语音喊停（MVP 必做）**：**本地** AEC+VAD 停播（不依赖云端取消生成）。KEY 单击打断兜底。二期上 WebSocket 流式时可云端取消。
9. **端云通信（MVP）**：**同步 HTTP**（整段：说话→ASR→DeepSeek完整回复→TTS→播放），简单可靠，延迟数秒可接受。**二期升级 WebSocket 流式**（边说边识别、边生成边播、可中途取消）。
10. **使用形态**：**便携电池为主**（18650），故二期唤醒需实测功耗。
11. **语言大脑**：OpenClaw + DeepSeek，意图理解、对话、任务分发、纠正/结束判定。
12. **汉字笔顺**：✅ D3 格式定稿——makemeahanzi 数据源（已实测跑通），OpenClaw 组 JSON（strokes SVG path + medians 骨架点），板子只渲染（LVGL 绘制 + 逐笔动画）。
13. **课表/故事存储**：OpenClaw 存 MD 文件；课表录入主路径为家长端。
14. **页面结构**：**4 页循环**（首页/课表/故事/查字），BOOT 单击循环切换。
15. **首页内容**：时间+日期+温湿度+今日日程+电量（常显信息牌）。
16. **屏幕**：ST7305 / 400×300 / 1bpp / 45-70FPS / 无前光。按键 ×3（KEY/BOOT/PWR）。
17. **图形库**：**沿用小智自带 LVGL**（单色模式），笔顺用 `lv_canvas` 绘制。
