# KidPal 小伴 · UI 设计 Brief

> 给 Open Design 用的界面设计需求文档。
> 目标：为 ESP32-S3-RLCD-4.2 儿童学习伙伴设计一套界面。
> **版本：v3**（v2 加趣味性后，v3 两处修订：① 吉祥物熊猫→**猫咪**；② 新增查字教学页字体红线 §3.3）

---

## 1. 产品一句话

一款面向 **8–12 岁孩子**的学习伙伴设备：平时是桌上常显的"信息牌"（时间/日程/温湿度），孩子按一下键就能用语音问课表、讲故事、查生字。

---

## 2. 硬约束（设计必须遵守，不可违背）

### 2.1 屏幕（最关键）
| 项 | 值 | 设计含义 |
|---|---|---|
| 尺寸/比例 | **400 × 300 像素，横屏（4:3）** | 所有设计严格在这个画布内 |
| 色彩 | **纯黑白 1bpp（每像素非黑即白，无灰阶）** | 只能用纯黑/纯白两色；**灰色层次只能用抖动(dithering)/网点/线条纹理模拟**，不能用真正的灰色 |
| 类型 | 反射式 RLCD，无背光 | 靠环境光，**高对比、大留白、粗线条**更清晰；暗处看不清，不依赖颜色深浅表达信息 |
| 刷新 | 快（~45-70 FPS） | 可以做简单动画（如笔顺逐笔写出），但 UI 以静态清晰为主 |

### 2.2 输入方式（影响交互设计）
- **无触摸屏**。
- **只有 3 个物理按键**：
  - **KEY**（主键）：单击=启动/结束语音会话、对话中打断、列表中选中
  - **BOOT**（辅键）：单击=在 4 个页面间循环切换
  - **PWR**：开关机
- **主要靠语音交互**（孩子说话）。

> 设计含义：**界面上不需要"可点的按钮"**。操作提示应是"按 KEY / 按 BOOT"这类物理按键引导，而不是触控按钮。导航极简（只有"翻页"和"确认"两种动作）。

---

## 3. 设计语言（风格方向）

> ⭐ **v2 修订核心：第一版设计被孩子评价"太正式"，本版重点加趣味性**。
> 问题诊断：初版太像"仪器面板"——等宽字体大时钟、规整表格线、整齐卡片，没有"伙伴感"。

### 3.1 必须有的趣味性元素（v2 重点）
1. **吉祥物角色「小伴」贯穿全局**：一个 **Hello Kitty 风格的极简猫咪**吉祥物（黑白剪影）——头部是**横向宽扁的圆（宽明显大于高）**，头顶两侧贴一对**扁小三角耳、与头部轮廓连成一体**（不悬浮、不竖长、不是河马/熊耳），小而低垂分开的圆眼、小小的鼻嘴，三根胡须、一条卷尾；2-3 个姿态复用。它不只是图标，而是"住"在界面里的伙伴：
   - P1 首页：站在角落（时钟旁/日程卡上），日常姿态
   - 聆听状态：竖起耳朵/凑近听的姿势 + "我在听！"
   - 思考状态：抓头/头顶问号的姿势 + "嗯…让我想想"
   - 播报状态：张嘴说话/挥手的姿势
   - 录音中：拿着话筒的姿势
   - 提醒弹窗：跳出来的姿势（像它发现了日程）
   - 低电量：打瞌睡的姿态（配合电量条）
2. **手绘感与圆胖线条**：轮廓用粗圆线条（不是细直线框）、边框带轻微不规则感（手绘抖动）、卡片圆角加大、关键元素可微微倾斜/错位（1-2°，不要整齐划一）。
3. **拟物&拟人细节**：
   - 时间冒号可以做成两只眨眼的眼睛（静态即可是够）
   - 温度计/湿度用卡通造型而非仪表盘样式
   - 故事页每条故事配一颗"故事果"图标（录的故事越多果子越多，收集感）
   - 笔顺演示配一只"握笔的小手"沿 medians 移动（替代干巴巴的高亮笔）
4. **装饰性涂鸦点缀**：页面角落少量星星/云朵/波浪线/小爱心（黑色剪影或网点），密度克制——点缀气氛，不抢信息。
5. **成就与奖励感**：讲完一个故事显示"故事徽章已收进本子！"式盖章画面；课表完成项可以打个卡通勾。

### 3.2 底层约束（不变）
- **童趣但克制**：8-12 岁，亲切可爱但不幼稚花哨（孩子已不喜欢"小宝宝风"）。趣味性来自"有角色、有表情、有惊喜感"，不来自满屏堆图案。
- **大字优先**：孩子识字量有限、远距离看，字号要大、字要少。
- **高对比黑白**：粗轮廓、大色块、清晰图标，避免细线和密集网点（RLCD 上糊）。趣味元素的线条也要粗、要大，缩小后不能糊成一团。
- **图标化**：辅助识字的年龄，重要功能配大图标 + 简短文字。
- **无渐变、无阴影、无彩色**：纯黑白 + 可选网点纹理。表情/姿态全靠黑白形状表达。
- **字体**：需要**中文字体**（优先圆体/胖黑体——比标准黑体更亲和；标题可用带手写感的字重），大字号下笔画不能糊。

### 3.3 教学页字体红线（v3 修订，孩子反馈后确立）
> ⚠️ **查字页（P4）是教学页，字形就是教材**。孩子会照着屏幕写，示范字必须「标准规范」，绝不能教歪。

- **P4 查字页的示范汉字**（米字格大框里演示笔顺的那个超大字 / 笔画轨迹）：必须用**标准规范字体**（思源黑体/Noto Sans SC 或规范楷体），字形横平竖直、结构标准。**禁用站酷快乐体等手写/趣味字体**，禁用手写抖动、禁止倾斜（不用 tilt）。
- **拼音、部首、笔画数、组词等伴随文字**：**可以继续用可爱趣味字体**（站酷快乐体等）——红线只针对米字格里那个会被孩子照着写的示范字形，其余信息文字不必跟着变正式。
- 其余页面（P1/P2/P3）的标题、装饰字、涂鸦可继续用站酷快乐体等趣味字体——红线只针对"教写字的示范字形"。
- 检验标准：把 P4 的大字截图打印出来，家长一眼能确认"这个字的标准笔顺和结构是对的"，孩子照着写不会写出错别字或歪字。

---

## 4. 信息架构：4 个页面循环

设备共 **4 个主页面**，按 BOOT 键循环切换：

```
P1 首页 → P2 课表 → P3 故事 → P4 查字 →（回到 P1）
```

需要为每个页面设计布局 + 页面间的统一元素（顶部状态栏、底部操作提示栏、页面指示器）。

---

## 5. 各页面详细需求

### P1 首页（默认页，常显，最重要）
**用途**：孩子瞟一眼就知道现在几点、今天接下来干嘛、屋里温度。
**必须包含**：
- 超大时间（如 10:24）——冒号可设计成两只眨眼的眼睛
- 日期 + 星期
- 温度 + 湿度（卡通造型图标 + 数字，如 22°C / 45%）
- "接下来"的 1-2 条今日日程（时间 + 课程名，如 14:00 钢琴课）
- **小伴吉祥物**常驻一角（日常姿态，如靠在日程卡边/坐时钟上）
- 电量指示（右上角小图标；低电时小伴打瞌睡可选）
- 底部操作提示：「按一下 KEY 说话」
**优先级**：时间 > 日程 > 温湿度。布局参考（仅供理解，可自由发挥，鼓励更活泼的构图）：
```
┌────────────────────────────────┐
│  10:24      星期三 6/26   🔋85% │
│  ┌────────┐  接下来：           │
│  │ 22°C   │  14:00 钢琴课       │
│  │ 45%    │  16:30 英语         │
│  └────────┘        ᕕ(◍‿◍)ᕗ ←小伴 │
│  ☀ 晴          [按一下 KEY 说话] │
└────────────────────────────────┘
```

### P2 课表页
**用途**：看今天的课程安排。
**必须包含**：
- 标题（如"今天的课"）
- 课程列表：每条 = 时间 + 课程名（+地点），一行一条，当前/即将进行的可高亮（反白）
- 可切换"今天/明天"（用 BOOT/KEY 切换，界面体现当前选中哪天）
- 底部操作提示：「按 KEY 问课程 / 按 BOOT 翻页」
**风格**：清晰的列表/表格，时间轴式或卡片式均可。

### P3 故事页
**用途**：看孩子自己录的故事，选一个听/看。
**必须包含**：
- 标题（如"我的故事"）
- 故事列表：每条 = 故事标题 + 日期，当前选中项高亮（反白）
- 底部操作提示：「按 KEY 选故事 / 说"我要讲故事"」
**另有 2 个子状态需设计**：
- **录音中**：明显的大状态提示（如大圆点 ● + "录音中…" + 已录时长），让孩子知道正在录。
- **故事正文**：选中后显示故事标题 + 正文文字（可滚动）。

### P4 查字页（教学核心）
**用途**：孩子问"某字怎么写"，屏幕大字显示并演示笔顺。
**⚠️ 字形红线**：这是教学页，**米字格大框里演示笔顺的示范汉字必须用标准规范字体**（思源黑体/楷体），横平竖直、结构标准，**禁用手写趣味体/抖动/倾斜**——孩子会照写，不能教歪（详见 §3.3）。拼音、部首、组词等伴随文字可保留可爱字体。
**必须包含**：
- **超大汉字**（米字格大框内，占屏主体，可达 ~250px，一笔一画分步显示）——字形规范、标准结构（正式字体）
- 拼音（带声调，如 yǒng）——可用可爱趣味字体
- 笔画数（如"共 9 画"）
- 当前笔顺进度（如"第 3 笔 / 共 9 笔"）
- 可选：部首、组词（如"力 ｜ 勇敢、勇气"）——规范正文字体
- 底部操作提示：「按 KEY 播笔顺 / 再问一个」
**关键交互**：笔顺是**逐笔动态写出**的（像看老师写字）——静态布局需体现"已写的笔画"和"当前笔"的区分（如已写=实心黑，当前笔=高亮，未写=浅网点轮廓）。

## 6. 关键全局状态（需单独设计）

1. **语音聆听中**：孩子按下 KEY 开始说话时，全屏或顶部明显的"我在听"状态（如跳动的麦克风图标 + "我在听…"）。这是最高频的反馈。
2. **思考中**：语音送云端处理时的等待状态（如"嗯，让我想想…"）。
3. **说话/播报中**：AI 在回答时（如声波图标 + 正在播放的文字）。
4. **提醒弹窗**：课表到点时，覆盖在当前页上的提醒（大字：事项+时间，如"该上钢琴课啦！"+ 提示音）。
5. **页面指示器**：让孩子知道当前在 4 页中的哪一页（如底部 4 个圆点，当前页实心）。

---

## 7. 需要交付的设计产出

1. **4 个主页面**（P1 首页 / P2 课表 / P3 故事 / P4 查字）的完整布局
2. **吉祥物「小伴」**：角色设定 + 6 个状态姿态（日常/聆听/思考/播报/录音/提醒，可选低电量瞌睡）
3. **全局状态**：聆听中 / 思考中 / 播报中 / 提醒弹窗 / 页面指示器（全部用小伴演出）
4. **统一组件**：顶部状态栏（时间/电量）、底部操作提示栏、图标集（麦克风/温湿度/课程/故事果/查字/电池/提醒）
5. **一套图标 + 推荐中文字体方向**（圆体/胖黑体）
6. 全部 **400×300 黑白** 呈现（可用网点表现层次）

---

## 8. 给设计师的提醒

- 这是**黑白墨水屏质感**的设备，想象"电子纸/Kindle"的观感，不是手机彩屏。
- **v2 最重要的提醒：孩子说"太正式"= 太像仪表盘/办公软件。要让它像一个"活的小伙伴住在里面"**——有角色、有表情、会眨眼、会凑过来听。检验标准：把设计给孩子看，第一反应应该是"它好可爱/它在看我"，而不是"这是个闹钟"。
- 信息**宁少勿多**——孩子 + 小屏，一屏一个重点。
- 每个页面都要回答："孩子不看说明书，能看懂现在能干嘛吗？"（靠大字 + 图标 + 底部按键提示 + 小伴的状态演出）。
- 中文显示是主体，确保中文在大字号下清晰、友好。
- 趣味元素的线条在 400×300 低分辨率下不能糊：形状大、轮廓粗、细节少。
