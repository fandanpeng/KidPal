- 日期：2026-11-03

- 范围：故事封皮、主页面循环、故事模块内部的进入与返回
- 文档性质：想法讨论记录，不替代 `docs/requirements.md` 等正式需求文档

## 已确认的主页面结构

主页面由三个增加为四个，顺序如下：

1. P1 首页
2. P2 课表
3. P3 星星积分本
4. P4 故事封皮

BOOT 短按在四个主页面之间循环：

```text
首页 → 课表 → 星星积分本 → 故事封皮 → 首页
```

故事封皮是故事模块的主页面入口。故事列表和阅读正文属于故事模块内部的子页面，不作为第五个、第六个平级主页面。

采用封皮层的原因：故事列表需要把 BOOT 用于列表移动、跳屏和删除，阅读正文也需要把 BOOT 用于翻屏。把故事列表从主页面循环中下沉一层后，既能保留这些页内操作，也能让 BOOT 在四个主页面之间持续循环。

## 已确认的按键规则

### 故事封皮

- KEY 短按：打开故事模块，进入故事列表。
- BOOT 短按：切换到主页面循环的下一页，即回到首页。
- KEY 长按：返回首页。

### 故事列表

现有页内操作保持不变：

- BOOT 短按：移动列表选中项。
- BOOT 双击：翻到下一屏。
- BOOT 长按：进入删除确认。
- KEY 短按：开始记录语境会话。
- KEY 双击：进入所选记录的正文阅读。

返回规则作一处调整：

- KEY 长按：由原来直接回首页，改为先返回故事封皮；在封皮再按 KEY 长按才回首页。

### 阅读正文

- BOOT 继续用于正文翻屏，保持现有行为。
- KEY 长按：退出阅读并返回故事列表，保持现有行为。

由此形成逐层返回路径：阅读正文 → 故事列表 → 故事封皮 → 首页。

## 封皮内容（已确认，2026-11-03 human 拍板）
