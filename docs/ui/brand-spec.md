# KidPal 小伴 · 设备 UI 品牌基调 v2（1bpp 手绘童趣系统）

> 服务对象：KidPal ESP32-S3-RLCD 400×300 反射屏 UI。v1 被 8–12 岁目标用户评为「太正式」，本版唯一主题是**趣味**——让它读起来像住进屏幕里的伙伴，而不是仪器面板。本文档供后续所有 KidPal 设计会话复用。

## 色彩 token（严格双色）

1bpp 无灰阶，常规六 token 在此坍缩为两枚＋三档网点纹理：

```css
--ink:    oklch(0 0 0);      /* 唯一前景 */
--paper:  oklch(1 0 0);      /* 唯一背景 */
/* 层次不用灰度，用网点（SVG tile 背景）： */
--tex-d50: url("data:image/svg+xml,…circle r=1.6 /4px 格…");  /* 半调·深 */
--tex-d25: url("data:image/svg+xml,…r=1.13");                 /* 半调·中 */
--tex-d12: url("data:image/svg+xml,…r=0.79");                 /* 半调·浅·腮红/未写笔画专用 */
```

反色是唯一的「强调色」：黑底白字反转块每屏至多一处（当前课程行、当前故事条目、提醒弹窗按钮位）。

## 字体

- **展示/标题**：站酷快乐体（ZCOOL KuaiLe），手写感圆胖；子集化内置。
- **正文**：思源黑体 / Noto Sans SC（Bold 子集）。
- **数字**：Baloo 2 ExtraBold（圆胖拉丁数字，时间大数字专用）。
- 字号阶梯：时间 112 / 页面标题 30 / 课程行名 20–22 / 辅助 14 / 下限 12。全部中文。

## 形状语法

- 手绘框：3px 黑实线 ＋ 不对称大圆角 `255px 15px 225px 15px / 15px 225px 15px 255px`（小元素取其半值）。
- 关键元素倾斜 token：±1°、±2°，每个画布 ≤3 处。
- 卡片大圆角；线宽下限 3px（设备像素），网点单元 ≥4px 格防缩糊。
- 网点面积占画面 <10%；只在腮红、未来事项分隔、未写笔画、弱化底纹四处使用。

## 角色：吉祥物「小伴」（猫咪 · Hello Kitty 风格）

黑色剪影语言：白圆脸身＋粗黑描边（7/200 头单位），**头是横向宽扁的圆（宽>高约 1.25:1），头顶两侧各一只扁小三角耳、自头顶连贯凸起（与头部描边连成一体，不悬浮、不竖长，Hello Kitty 式）**，纯黑件＝小而低垂分开的圆眼珠、小鼻嘴、卷尾巴，脸颊三根胡须向两侧放射；腮红用 d12 微点阵。整体追求极简可爱的宽圆脸猫，避免长脸/竖长耳/复杂五官导致的"怪"。表情靠眼睛/嘴形道具级变化。七姿态：日常、聆听、思考、播报、录音、提醒跳起、低电打盹。

## 动效预算

反射式 RLCD 刷新快，但动效要克制：眨眼 4s 一次、录音频闪 600ms、播报嘴部 220ms、笔顺演示 900ms/笔。禁止整屏高频闪烁与装饰性循环动画。

## 姿态规则

- 无触摸、无鼠标暗示：界面上不出现任何「可点按钮」样式；一切操作引导用物理键帽 `[KEY]` `[BOOT]`。
- 底部统一键帽提示条（左提示·中间 4 点页面指示器·右提示）。
- 涂鸦点缀（星、云、波浪线）每屏 ≤2 处，黑色剪影或网点。
