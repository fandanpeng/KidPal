## 1. 背景与产品定位

给 8–12 岁小朋友做一个随身学习伙伴。设备本地做「感知 + 显示 + 交互」，云端做「理解 + 生成 + 存储」。

**主要功能是对话。** 孩子在首页按一下 KEY 进入免提对话，连续追问不用反复按键。对话能力分两层：

1. **通用问答** — 百科、闲聊、孩子脑袋里冒出来的任何问题（「天为什么是蓝的」），随口问、听得懂的回答。
2. **专项能力**（对话发起，专属页面承接展示）：
   - **问课表** — 对话中问「明天有什么课」，答复跟百科问答一样在问答框里给（v1.19 口径：不嵌课表页；说「帮我显示课表」才切课表页）；
   - **帮我记录**（承载 = F2「星星记录」）— 孩子口述故事/日记/碎碎念，实时转写归档，可回看；
   - **查生字** — 对话中说「勇怎么写」，弹出专门的**查字窗**整屏米字格展示笔顺演示（会话内窗口、非常驻页面，v1.36 撤 P4）。

**设备定位**：它**首先是个"常显的信息牌"，其次才是语音交互设备**。平时 90% 时间常显在桌上/书包旁，孩子瞟一眼要回答的是他真正关心的那个问题——「**接下来我该干嘛**」。常显主体 = 接下来的日程与到点提醒，时间/温湿度/电量这些环境信息退居辅助位（孩子不在乎屋里多少度）；同时常显页要有小伴的趣味演出与互动点缀（吉祥物姿态、表情、小彩蛋），别做成一张全是待办的冷冰冰任务清单。孩子有事了才按一下 KEY 进入免提对话（或用 BOOT 翻页浏览），说完超时/按键自动回常显——会话生命周期的完整示意以 §2.1 为唯一权威。

## 2. 共享底座：语音会话生命周期、按键与页面结构（所有 story 复用）

### 2.1 语音交互模型（已定：按一下 KEY / 喊唤醒词启动会话；KEY 打断停播）

**核心：按键只是"激活开关"，一旦激活进入免提会话，无需一直按住。**

```
【常显】屏幕常显信息牌（接下来日程 + 提醒为主，时间/温湿度辅助）
   │ 按一下 KEY，或喊唤醒词「你好，小智」（Phase 1 双入口）
   ▼
【对话态】设备提示音+屏幕显示聆听中
   │ 孩子说话（聆听中·逐句回显）→ 说完一句切「思考中」→ 设备回应（播报中）→ 继续聆听；可连续追问，不用每次按键
   ▼
【结束】三种任一：
  ① 超时：60 秒无语音 → 自动关闭，回常显
  ② 孩子说"拜拜/不用了" → 判为结束意图 → 关闭
  ③ 再按一下 KEY / BOOT → 手动关闭（BOOT = 关会话**回原页、不翻页**——v1.39 覆盖层 BOOT 隔离口径）
```

⚠️ **60 秒超时实现侧对账（2026-09-14 查证登记，Phase 1 修复项——需求先行、代码后改）**：设备侧 `SESSION_TIMEOUT_60S` 只有状态机逻辑与验收测试注入（`session_state_machine.cc`），活侧无 timer 生产者（`ses_machine_dispatch` 全仓仅 `test/*.acceptance.c` 调用）——**真机 60 秒自动关闭从未发生**。MVP 实际代管超时 = 引擎侧 120 秒无语音 LLM 告别语 + 180 秒硬断（已于 2026-09-14 配置修正为 24h 兜底 + 告别语关闭，机制与修正见 arch §6.4 / §10 决策 21 注记）。Phase 1 接线 = 设备侧补 timer 生产者；**录音态例外已定 = 120 秒自动收尾归档（2026-09-14，开放问题 7 收口）**。

**唤醒词入口（Phase 1，2026-09-13 升入）**：喊「你好，小智」与按一下 KEY 均可启动会话，其余会话逻辑不变——MVP 开发期间已在小智固件上实测唤醒可用（WakeNet 本地检测，双麦硬件已支持）。定制品牌唤醒词「你好，小伴」需换 WakeNet 模型，非 Phase 1，后续再做。

**打断停播（Phase 1）**：AI 播放中 KEY 单击 = 立即停播并聆听，100% 可靠——Phase 1 只做这一个打断手段。

**音量语音调节（Phase 1，2026-09-14 定）**：会话中说「声音大一点 / 声音小一点」即调播报音量，调节后语音简短确认（如「好，声音调大了」）——设备无实体音量键，语音是唯一调节入口（底座能力，任意页会话中可用）；档位数量与步长归实现期定。

**语音喊停（二期，2026-09-13 定为不纳入 Phase 1）**：原 MVP 计划标「必做」、实际未交付，亦不纳入 Phase 1——播放中孩子**一开口（不管说什么）AI 立即停下并聆听**，既是喊停又是自然插话（"不对，是勇敢的勇"→ 纠正重答）。依赖本地 AEC+VAD 实时检测、阈值需实测调优（架构侧最大不确定点），不挡 Phase 1；二期落地时 KEY 单击打断保留兜底。

**记录会话（2026-09-14 定稿：P3 双入口 + 聆听语义分流）**：入口① 在星星记录本**按 KEY**——会话**预置记录语境**，屏显引导「需要我帮你记点什么？」，孩子直接开说、**无需触发词**；本会话**一刀切纯记录**（说的内容全部累积，不做逐句意图切换——想提问去其他页按 KEY，2026-09-14 human 裁）。入口② 任意页说「我要讲故事」/「帮我记下来」（触发词判意图，原有链路不变）。聆听语义与问答分流：**问答 = VAD 切句逐句回复；记录 = 整段累积、AI 不逐句回复**（切句只用于话语回显），**显式收尾**（说「我说完了」/「讲完啦」，再按 KEY 兜底）才停录 → 归档 → 盖章 → 确认播报。记录语境的聆听态复用 WF-B-01 布局、气泡文案换引导语。机制支撑 = arch §5.1（故事归档组件·`start_recording` 时机扩展）。**录音态超时（2026-09-14 定，开放问题 7 收口）**：录音态**不适用 60 秒会话超时**，改 **120 秒无语音 → 自动收尾归档**（走正常盖章演出、收尾后回 P3 列表，不丢弃）——孩子讲故事中途停顿属常态，60 秒会把故事拦腰截断碎成两篇；120 秒盖住正常停顿，真离开则归档无害。问答会话维持 60 秒不变（双阈值随 60 秒 timer 接线一并落地，见上方 ⚠️ 对账）。

### 2.3 按键手势（3 键，无触摸；本节为权威键位定义）

##### S-F1.1 · 常显首页看「接下来干嘛」

> 作为孩子，我希望瞟一眼就知道接下来该干嘛（时间、屋里冷暖顺带瞟到），以便不用问大人。

**验收标准**
- AC1：Given 设备常显在首页，When 孩子看屏，Then 「接下来」文本列表为主体展示（时间+课名同行、多项正常换行、常规字号），联网状态/时间/日期/温湿度/电量收进辅助条小字不与日程抢视觉重心（辅助条各项**图标前置**：📶 联网小标打头，温/湿度/电量各带小图标，湿度 45% 不裸数字挨电池；**日期英文简写**，如 Tue 22 Sep = 星期简写+日+月简写、无「今天」字样，v1.57）；小伴常驻演出（姿态/表情随时段与日程变化，如临近上课做出门准备状），页面带倾斜点缀等趣味细节——不是一张冷冰冰的任务清单。
- AC2：Given 今日有日程，When 看「接下来」列表，Then 学校课合并为一项「XX:XX 上学」，培训班/一次性安排逐项列出（时间+课名同行、正常换行）；下方「明天」区多项逐行列出明日安排——**明日日程全量进区**：学校课合并为一项「XX:XX 上学」（与「接下来」区同款合并规则）与课外班、临时事件同列，按开始时间升序（2026-10-11 human 改判，翻转 v1.57「仅课外班与临时事件」OQ2 口径）。
- AC3：Given 电量低且未充电，When 电量 ≤ 阈值（现实现 15%），Then 辅助条电池图标每秒闪烁提示该充电；一旦充电即停闪（充电「叫醒」）。**不做小伴睡姿演出**——低电不占小伴姿态通道（2026-09-13 砍，见 §8 已砍清单）。
- AC4：Given 设备断网，When 看屏，Then 时间/温湿度/电量照常本地显示、日程区不更新（回引 NFR-OFF-1），且**辅助条联网小标变断网态（WiFi 斜杠图标）**——孩子能一眼看出「现在没连网」（链路已实现：基座 `GetNetworkStateIcon` 断网返回 WiFi-slash，另有强/中/弱三档信号）。
- AC5：Given 当日日程数据已送达（设备在线），When 今日再无剩余安排，Then 「接下来」区显示「今天接下来没有安排啦」——不再整区留白（v1.61）；话术按 v1.58 纯文本同款字号渲染、只占位不破布局优先级（接下来 > 明天区 > 小伴演出）。
- AC6：Given 明日非上学日且无课外班与临时事件（明天区确无项），When 孩子看「明天」区，Then 显示「明天没有什么课喽」（同款字号、同占位规则）；Given 明日是上学日（纵无课外班与临时事件），When 看同区，Then 至少显示「XX:XX 上学」一项、不出现空态话术——「空态联动上学日」（2026-10-11 human 裁，改判后由「上学」项本身承载，无需独立话术）。

## 4. 体验与视觉风格

> 本节只管**全局原则层**——跨页面/跨状态的设计原则；各页、各窗口的具体版式以 §2.4 页面图与 F1–F3 story 内线框为准，本节不重复（v1.40 收口：原「大字体、高对比黑白、图标化」总述撤销，「图标化」无独立信息量、随各页线框自然表达；查字版式细目归位 F3）。

- **可读性分级（v1.40，替代原「大字体」总述）**：屏幕 400×300、1bpp 纯黑白、无灰度——**字号随信息优先级分级，不追求处处大字**：孩子一眼要看的关键信息（提醒大字、星星计数等）用大字（v1.57：「接下来」改常规字号文本列表——退出大字例举）；信息密度高的面（P2 课表网格、P3 阅读正文）允许小字，小字可读性下限受 NFR-READ-1 约束（实测前按可读字号排版、行数自然变多、滚动承接）。
- **动态能力边界**：RLCD 刷新快（~45-70 FPS，官方 Demo 文档口径、未真机实测——同 arch §5.3.1 驱动 IC 口径注），**滚动、简单动画、笔顺动态演示都可行**，交互不必局限于翻页式。（网点 dithering 可模拟灰度层次，但**全局口径待拍**——见 §7 开放问题 1。）
- **趣味性要求（v2，孩子反馈"太正式"后确立；v1.4 升格为常显页构成原则）**：设计需有**吉祥物角色「小伴」（猫咪）**贯穿全局（首页常驻 + 各状态换姿态：聆听/思考/播报/录音/提醒）；常显首页以「接下来日程 + 小伴演出」为主体、环境信息退居辅助条——趣味与互动是常显页的构成部分，不是事后装饰。手绘感圆胖线条、拟人化细节（眨眼冒号、卡通温度计、星星收集——原「故事果收集」，2026-09-14 随 P3 改名）、克制的涂鸦点缀。检验标准：孩子第一反应是"它好可爱"，不是"这是个闹钟"。详见 [UIUX-DESIGN-BRIEF.md](ui/UIUX-DESIGN-BRIEF.md) §3.1。
- **查字窗教学字体红线（v3）**：查字窗是教学面，**米字格大框里演示笔顺的示范汉字必须用标准规范字体**（思源黑体/楷体），禁用手写趣味体/抖动/倾斜——孩子会照写，不能教歪。拼音、部首、释义等伴随文字可保留可爱趣味字体。详见 brief §3.3。
- **边界与指针（v1.40 收编原三条：查字版式细目 / 字体类需求 / 设计侧输入）**：各页/各窗口的具体版式（含查字窗米字格尺寸、白衬边当前笔等细目）以 §2.4 页面图 + F1–F3 story 内线框为准，本节不重复；字体类需求住本节（教学字体红线条），技术支撑锚 = [architecture.md](architecture.md) §5.5（开发视图：资产管线 §5.5.2 / 字体管线 §5.5.3）；设计侧输入 = [ui/PHASE1-DESIGN-INPUT.md](ui/PHASE1-DESIGN-INPUT.md)（本轮梳理设计相关变更的汇总索引，非需求权威；冲突以本文件为准）。

## 5. 非功能需求（NFR）

> 每条四件：量化阈值、验证方式（怎么实测）、支撑锚（arch §x.y）、可行性三态。story 内的相关表述 = 该 NFR 在具体场景的具体化并回引本章 ID；同一约束全仓只在本章定义一次。NFR 只管「产品必须做到什么」；技术实现约束（介质禁令、证书形态、provider 配置约束）归 architecture.md。未拍数值的阈值带「待定」标迁入，数值拍板走后续立项。

### NFR-PERF-1 · 思考响应不冷场
- 阈值：孩子说完到设备开口，等待超 **4 秒**必须先播安抚句，不冷场。
- 验证：260829-voice-roundtrip 包闭环（VRT-A5：4s 安抚句到达即播）；live 冒烟多轮在档。
- 支撑：arch §5.1（front 组件·安抚定时器）
- 可行性：✅

### NFR-PERF-2 · 查字端到端延迟
- 阈值：从问「X 怎么写」到查字窗弹出（完整示范字可见），目标 **5 秒档**——human 2026-09-13 裁：需求保留，实际效果优化归 Phase 1；v1.59 阈值终点重锚：笔顺演示改 KEY 起播后「演示开始」由孩子按键决定、不再是对答链路的可测终点，终点取「窗弹出、示范字可见」——与下行验证句实测记时口径（「查字窗打开」）归一。
- 验证：260829-char-stroke 包 CHR-A9（live 口径不 auto-run）；2026-09-15 真机复验链路恢复可跑（串口实测语音应答→查字窗打开 ~21.6s，5 秒档未达、优化归 Phase 1）。
- 支撑：arch §5.2 场景③（查字链路）、§5.1（查字组件·笔顺渲染）
- 可行性：✅（链路可行性已实证；延迟达标未验，优化归 Phase 1——与 S-F3.1 同链两缺陷修复后复测）

### NFR-SEC-1 · 传输安全与强制鉴权
- 阈值：公网入口必须带设备 token（≥128-bit 随机），未设 = 拒绝服务，不留 validation-mode 后门；传输 = wss + 自签长期证书（有效期 ≥10 年，把到期死局推出产品生命周期）。
- 验证：260903-device-ws-switch / 260903-gateway-directionB 包闭环；十年期证书已在用（human 2026-09-13 视同通过；轮换脚本/到期告警子项不拆，一句话覆盖全条）。
- 支撑：arch §6.1（鉴权与传输安全）、§10 决策 22
- 可行性：✅

### NFR-SEC-2 · 儿童数据出网记账
- 阈值：无技术阈值——四条出网路径（① 语音音频 → 阿里云 ASR（境内）；② 转写文本 → OpenClaw → DeepSeek 云；③ 回复文本 → edge-tts（微软非官方接口）；④ kidpal agent 实时事实查询回合（天气/新闻/今日热点类）经 OpenClaw 平台联网搜索（Tavily）出网查询）human 已知晓并接受（①–③ 2026-09-03；④ 2026-10-12 human 裁接受）。④ 行为口径：实时事实查询回合**先播「我去查一下」式提示再真查**（不静默干等、不无依据抢答），**只依据查询结果作答**；查不到或查询失败时诚实说不知道并引导（换个问法再试/换个话题），**不编造**。
- 验证：①–③ 决策记账完成（arch §10 决策 19）；④ human 意图原话即接受证据（2026-10-12）：「原来在 openclaw 主环境时可以查 天气的，"孩子对话回合禁工具、一回合作答" 这个对于实时信息 应该查询，可以提示，我去查一下，然后开始查，这样体验也不会差」。
- 支撑：arch §1.2（外部依赖清单·出网记账）
- 可行性：✅（已接受风险记账，非可行性问题）

### NFR-OFF-1 · 离线边界
- 阈值：断网时仅时间/温湿度/电量可用；无提醒、课表/查字/问答不可用（查字/ASR 需联网，给友好提示）；设备不缓存任何事项（RAM 渲染缓冲不禁、掉电即失——见 arch §6.2 澄清）。
- 验证：260829-schedule-reminder 包闭环（RMD-A7 断网无提醒）。
- 支撑：arch §6.2（离线边界与介质禁令）
- 可行性：✅

### NFR-SAFE-1 · 内容安全
- 阈值：答案口语化、简洁不啰嗦、适合 8–12 岁（生成端约束；**不设硬性句数上限**——human 2026-09-25 裁：纪律管「不啰嗦」不管句数，故事播报按段落成段讲、不逐段请示，打断手段 = KEY 单击停播在案）；Phase 1 接受 system-prompt 级约束 + ACCEPT-AS-RISK 记账；明确排除「家长逐条审批」形态；机械内容过滤层留作日后合规选项。**联网查询转述边界（2026-10-12 增，随实时事实查询批）**：联网查询结果面向孩子转述时守同一儿童化口径——外部内容不逐字照搬，儿童化改写后转述；不出现系统词/技术词/不当内容；不合适内容降级为「没查到合适的」。
- 验证：human 2026-09-03 裁定在案（决策 28）；超限按有处理的失败模式（截断/分屏）而非仅记遵循度缺陷。
- 支撑：arch §6.3（错误处理与降级）、§10 决策 28
- 可行性：✅

### NFR-READ-1 · 1bpp CJK 字号可读性下限
- 阈值：**14px**（2026-09-15 真机实验定案——10/12/14/16/18/20/24/28/32px 九档 1bpp NotoSansSC 同屏对照（lv_font_conv 产线同源参数、实验固件真机目测）：14px 基本清晰、12px 起不可辨。CJK 正文下限 = 14px，产线 font_body.bin 14px 贴线成立；设计稿 12–16px 细字一律按 ≥14px 收）。
- 验证：已完成（ARQ-260831-small-cjk-1bpp-readability 实验落地——一次性实验固件烧真机对照，human 指示跳过流程、已如实记录；实验页已撤）。
- 支撑：arch §5.5.3（字体管线）
- 可行性：✅（阈值已实测钉死）
