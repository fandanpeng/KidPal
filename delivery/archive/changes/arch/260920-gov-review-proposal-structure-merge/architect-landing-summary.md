## 3. 落地中的事实性偏差（如实申报）

1. **census 首版写错（本批自证，已如实记录于 §2）**：初稿用 `grep … \| grep -v "PROPOSAL.template.md"` 想排除模板**文件**——但 `grep -v` 过滤的是**行内容**，凡行文提及该路径的整行被吞（`path-form-family.md:64`、`gov-arq/SKILL.md:12`/`:34` 三行）。改用不带 `-v` 的完整模式重跑得 **12 处 / 5 文件**。**这正是「枚举 census 须注明命令、遇省略须逐条展开」要防的形态——过滤口径写错 = 静默漏项。** 该过失已写进 §2 T2 的「本批自证」段（作为硬项 · sweep 透镜义务的反面教材）。
2. **V4 的模式收窄（R1-F2 连带）**：v0.3 的 V4 用裸 `硬项 1a` 模式会**误命中模板内的留痕引用**（4 处「原『硬项 1a』」式历史注记是有意保留的溯源）。落地版改为**标签本体**形态（`【硬项 1[abc]` / `【硬项 2a`），并如实申报该更正。
3. **模板 :6 的漏改（自查发现）**：v0.3 的 T2 改法清单列了「模板本体 4 处标签 + `:6` 引用」，但**本件落地时 Write 新版漏掉了 `:6` 的改动**——起草后自查（`grep -n "硬项" template`）发现并当场补改。**该漏改与本件「起草期实证义务」的第 7 条（搬运引据须复证）同源**：`:6` 的命中在 T2 的 census 表里有（#5），但 Write 时凭记忆重写而未逐条对照 census。
4. **五段式示范的两处形态约束**（读法注）：**锚行必须裸起、不得加粗**（`ARQ-260914` 记录的原始错误形态）；**解析器不跳 fenced code block**（§2 内无法示范锚行字面形态，本件改用 `〔第五段·锚清单〕` 前缀标记绕开）。两条均写进模板正文（读法注）。
