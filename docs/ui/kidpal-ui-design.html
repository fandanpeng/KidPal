400 × 300 纯黑白界面

一套为反射式 RLCD（无背光、1bpp、非黑即白）设计的界面。所有层次只靠纯黑、留白与网点抖动表达；导航只有两个动作——「翻页」和「确认」。下面每一屏都是真实的 400×300 画布。

400 × 300 px · 4:3 横屏 1bpp 纯黑白 · 无灰阶 无触控 · 3 物理键 语音为主交互 中文大字号
实心黑 = 强调 / 选中 / 已写笔画 网点 = 次要 / 未写轮廓（非真灰） 白底 = 主体留白
01

四个主页面（按 BOOT 循环）

P1 首页 → P2 课表 → P3 故事 → P4 查字 → 回到 P1。统一元素：顶部状态栏（页名 + 电量）、底部操作提示栏（物理键引导 + 页面指示圆点）。为便于评审，下图按 2× 放大显示，内层坐标严格是 400×300。

02

P3 故事页 · 两个子状态

录音中必须「一眼可见正在录」——用大实心圆点 + 大字 + 已录时长；故事正文用于回看文字稿，可滚动。

03

全局状态（覆盖在任意页上）

语音是主交互，「聆听 / 思考 / 播报」是最高频反馈，必须占据视觉中心；提醒弹窗到点覆盖当前页。

04

统一组件 · 图标集 · 字体方向

所有页面共用同一套顶栏、底部提示栏、按键帽与图标。图标只用纯黑描边/实心，不用细线密纹，保证 RLCD 上不糊。

推荐中文字体方向

大字号下笔画不能糊，气质「童趣但克制」——选偏圆润、字重大、字面开阔的黑体/圆体，避免细宋体。数字与拼音用等宽体，时间一跳一跳不抖动。
