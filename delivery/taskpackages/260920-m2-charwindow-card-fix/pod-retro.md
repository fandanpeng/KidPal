## 卡点与体感

1. **这是几棒以来最省力的一包，省力的原因值得说清：机制在 triage 期就钉死了，builder 拿到的是「不用猜的靶」**。字体接哪个体、meaning 进不进降级闭集、缺失兜底长什么样——三问全部在触点①由 human 拍死，reviewed plan 写到「builder 若需重新发明机制说明 plan 失职」的密度。结果内循环零返工轮、mutation 证据我在派 verifier 前就补齐（A3 那条是我单独向 builder 要的，因为它的变异面与 A1/A2 不相交）。对照上一包：K3 的返工大头是「验收面欠覆盖 + 拆包产物腐坏」，这一包两样都没有——**因为入口就不同：这一包是 triage 门进来的，拆包快照腐坏问题从结构上不存在；plan 是 architect 对着磁盘现写的，不是几天前的快照**。入口质量决定整棒体感，这条我信了。

2. **这一棒最大的卡点是我自己：spec v1.56 起草时把设计注释当成了已落地代码**。我写「全工程中文页面均显式加载 font_body」——实际上 `lv_font_load` 全树零运行时调用，那三行是 schedule_page 里的设计注记，font_body 接线是 human 早已裁过的 residual 后续包。architect 比例化 review 抓出来，我对磁盘逐条核验后确认，勘误行 append-only 落账。**这是我第二次在同一族坑里摔**：K3 的 A5a 假绿是「注释里的字面满足齿」，这次的 v1.56 勘误是「注释冒充已落地先例」——同根，都是把注释里的文字当成了代码事实。修正动作很具体：**引用「某机制已存在」时必须 grep 到运行时调用行，注释和设计文档一律不算**。这条已写进下次改进。

3. **防伪齿（A1 负向齿）这轮真正跑出了它的设计价值**：builder 的变异就是「把病灶改回去」——恢复 `LV_FONT_DEFAULT` 实参，负向齿立刻红，红名直接指认那一行。齿的敏感性与病灶同构，不存在「齿绿但病还在」的缝隙。对比 K3 A5a 那条正向包含齿（注释写一遍就算过）——两种齿形态的差异不是学术的，是「真机轮会不会再抓出隐身 bug」的差异。**以后凡是「X 不应存在」类的实现约束，优先钉负向齿；正向齿只用于「必须存在的接线」且必须注释剥离后计数。**

4. **设备构建闸又抓到一条 host 永远测不出的真问题**：五行拼装后 `buf[256]` 触发设备侧 `-Werror=format-truncation`——host 根本不编 char_page.cc，这条红在 host 面原理上不可见。builder 放大到 384 修平，且如实报告为「正确性伴随」而非顺手重构（判断正确：不改它，设备上释义行会被截断或构建直接红）。**这已是连续两棒实证「host 全绿 ≠ 设备能编」**，设备构建闸不能静默跳过这条纪律的性价比，比任何条文论证都有说服力。

5. **一处我有意没扩面的判断，记下我的理由**：integrator 开了条 NIT——char_stroke.h 注释里 changeId 笔误（240920 应为 260920），post-fact 不就地改（保「已验 diff == 冻结 diff」不变式）。我认同维持 NIT 不修，与上一包我推翻「CMakeLists 假陈述留后续批」**不矛盾**：那一条是「代码是否接线」的行为性假陈述，会误导下一个维护者；这一条是标识符笔误，零行为误导、纯追溯成本。**「本包引入的错误必须本包修」的判据应该是误导性，不是出现位置**——行为性假陈述不留主干，标识符笔误进 NIT 池。

## 别扭的 acceptance / 帮倒忙的钩子

- 无新增钩子摩擦。commit-safety 的「staged 为空」误导提示本包又出现两次（第三棒连续在案），依旧靠多跑一步 `git diff --cached --stat` 消化。
- A4 的 mutation 语义归位走了一步弯路：我最初把它写成普通 acceptance 条目，mutation 闸必然找它要证据——但它本质是套件级留痕修订项（验收文件自身内容），无实现侧行为可变异。改成 `kind: structural` 归位的是 mutation-check 自己的豁免语义（同 K3 A7/A8 形态），不是绕门——但**这件事本该在起包时就想清楚**，验收条目的「可变异面」应该在起草期就逐条判定，而不是等闸报红再回头改类型。

## 下次改进

- **spec 起草硬规则：凡写「某机制已存在/已接线」，必须 grep 到运行时调用行**——注释、设计文档、review-packet 记载一律不算证据。已付两次学费（K3 A5a 假绿、v1.56 勘误），第三棒不该再犯。
- **验收条目起草期逐条判「可变异面」**：无实现侧行为可变异的条目（纯留痕/纯真机/套件级守卫）直接 `kind: structural`，不留到 mutation 闸才补。
- **负向齿优先原则**：「X 不应存在」类约束钉负向齿（现状红、修复绿）；正向齿必须注释剥离后计数。
- **triage 门的触点设计经验**：把方案选择收敛成 2–3 个具体二选一，human 一次点完；不开开放式讨论。
